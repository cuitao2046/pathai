# RF-B-SR1 信标 AT 配置命令清单（现行台账 · 61 枚）

> 发射功率统一 **-10 dBm**（设备档位无 -8/-12，见 docs/08 §1.3）  
> 广播间隔：取台账 `broadcastInterval`（当前全部 300 ms）  
> ⚠️ **RSSI@1m 为占位值 -59 dBm（`C5`）**，须现场标定后替换（标定流程见 `docs/28-定位参数现场标定方案.md`）

## 使用方式与注意事项

1. 手机装 **nRF Connect**，搜到信标（默认名 `RFstar_XXXX`）并连接。
2. 在 **RX 特征值**（写入通道，UUID `6E400002…`）逐条发送下列命令；**AT 指令须大写、不带回车换行**。
3. 主机端 MTU 须 **≥128 字节**，否则指令无法设置。
4. 每条指令回 `OK` 才算成功；`FAIL`/`ERROR`/`BUSY` 需重试（`BUSY` 为上一操作未完成）。
5. 所有设置指令**立即生效且掉电保存**，无需 RESET/SAVE。
6. ⚠️ `AT+ADS` 的**模式必须保持 1（可连接）**；一旦设 0 不可连接，将**永久无法再改任何参数**（整台报废）。
7. 建议先执行 `AT+NAME` 命名，便于在 nRF Connect 中区分各信标。
8. `AT+AUTH=0` / `AT+ENCRYPT=0` 为幂等确认：鉴权或加密一旦开启，扫描端将解析不出 UUID/Major/Minor。

## 四、RSSI@1m 现场标定（替换清单中的占位值）

`RSSI@1m` 是 **1 米处的参考 RSSI**（measured power），与发射功率 `AT+POWER` 是两个不同的量：
本方案把发射功率降到 -10 dBm，1m 参考值会同步下降约 10 dB，因此**不能照抄 -59**（该值是 0 dBm 档设备的典型值），必须现场实测。

步骤（完整流程见 `docs/28`）：
1. 信标按本清单配置并固定到位后，手机置于其正下方 **1 m** 处；
2. 用扫描工具读该信标 RSSI，多次采样取中位数（避免手抖/遮挡）；
3. 负值转补码 hex：`字节 = (256 + RSSI) & 0xFF`（-57 → C7、-62 → C2、-69 → BB）；
4. 把该值替换进对应信标的 `AT+BEACON` 第 4 参数后重发（其余参数不变）；
5. 全楼统一典型值时，可批量替换清单中所有占位值。

> 本清单由 `src/tools/gen_beacon_at_commands.py` 依据 `result/ble_deployment.json` 生成；台账更新后重新运行即可（生成器另产出 `result/beacon_provisioning_plan.json`）。
