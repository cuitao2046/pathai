## 〇、坐标框架说明（务必先读）

地图坐标采用**局部米制坐标系**，与 `result/school_building_01_map_v9.geojson` 完全一致：

- 比例尺：`1 pt = 0.0529 m`
- 原点（CAD 工程坐标）：`(2019.1, 1154.8) pt`
- 变换（pt → 米，Y 轴翻转）：
  - `x_m = (x_pt − 2019.1) × 0.0529`
  - `y_m = (1154.8 − y_pt) × 0.0529`
- 指南里说的"以主入口为 (0,0)"是简化表述；**实际基准是上述 CAD 原点**，现场实测必须换算进同一米制框架才能直接比对。

**现场最稳的测量法（锚点法）**：

1. 在 `refs_*.csv` 里挑一个明显、易找的控制点作为**锚点**（如主入口节点），记下它的图纸坐标 `(x0, y0)`。
2. 以锚点为现场 (0,0)，用激光测距仪量出其他控制点相对锚点的偏移 `(dx, dy)`（米）。
3. 该点实测图纸坐标 = `(x0 + dx, y0 + dy)`。
4. 工具 `compare` 支持直接填 `anchor` + `meas_dx_m/meas_dy_m`，自动完成第 3 步。

## 四、执行顺序与回写

1. **几何**（定坐标基准）→ 2. **语义**（边走边核对房间牌）→ 3. **无障碍**（针对性核查设施），一趟走完两层。
2. 回公司把记录回写 GeoJSON 四层结构（`geometry` / `semantic` / `topology` / `accessibility`）。
3. 跑 `validate_geojson.py` 验收：几何精度 <0.3m、房间语义 100% 一致、无障碍要素全部核实。
4. 生成指纹采集网格（第八章）前，确保本表全部偏差已闭环。
