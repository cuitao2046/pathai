# 现场实验小程序使用说明

入口：**设置 → 现场采集工具 → 打开现场实验**。顶部有四个菜单：**真值登记 → 任务 → 信标巡检 → 场记及导出**。

**第一次使用**：进「任务」，打开「使用候选点试采」，选一个 T3、T4 或 T6 点位，跑一遍采集。试采每段 10 秒，不计入正式批次。要验证真实信标和上报，请在设置中打开「真实信标（live）」并重启小程序。模拟信标只用于试采，记录不上报。

**正式采集**：先巡检信标，再使用当前生效的正式清单。每项任务首次登记时发布一次，后续日期沿用。点位或真值有调整时才到「真值登记」发布新版。离场前检查「待补传」是否为 0，并保存场记。

## 1. 真值登记：量清点位，发布清单

| 菜单或按钮 | 怎么用 |
| --- | --- |
| **任务、点位下拉框** | 先选任务和候选点。页面会带入参考墙和距离，自动反算 `base` 坐标，并显示与候选坐标的偏差。 |
| **保存该点复测** | 实地测量后，仅修改与参考值不同的距离（米）。换算坐标只读。距离不变时沿用当前版本，有变化则保存为 `v1`、`v2` 等，旧版本仍可查看。缺少任一方向的参考墙时，须先补齐参照再登记。 |
| **复制候选真值并发布** | 首次登记时使用。确认后把通过校验的未登记点保存为候选 `base` 真值，和已有的最新复测结果一起发布。跳过的点位会显示编号。 |
| **仅发布已登记的真值** | 点位调整后，用最新已登记的真值发布新版。系统按发布日期分配「日期-序号」批次号，如 `20261119-001`。若真值内容相同，沿用当前批次。 |

复测版本保存在当前手机。发布会纳入该任务下所有已保存的复测点，并固定每点的最新版本。更新读数后需重新发布，已经发布的清单仍保留原坐标。当前不能逐点勾选发布子集。T3 要 12 个点，T6 要 18 个点，T7 试走用 8 个 CP，T8 正式清单含 8 个 CP 和 4 个 P，T4 最多 256 个网格点。现场放样方法见 [现场测点准备](field-survey.md)。

## 2. 任务：按清单采集

选**任务和采集日期**。正式采集时关闭「使用候选点试采」，选用该日期生效的清单。T3、T4、T6 从地图点选采集点，可拖动和缩放。点选后地图高亮测距墙，底部显示参考墙、测距距离和采集操作。先按复测读数或地面标记站到点位，再按开始。同一清单的 T3、T4 进度可跨日延续，T6、T7、T8 按采集日统计。

| 任务 | 开始后做什么 |
| --- | --- |
| **T3 参数标定** | 每点采一次 120 秒。整批上传后，在本页「定位常量计算」生成正式标定样本并开始计算。后端将每点的原始数据切成三个连续的 40 秒窗口，分别统计 RSSI 后一起拟合。核对默认值与拟合值后，可应用拟合参数与网格。 |
| **T4 指纹建库** | 点「开始采集」，按提示依次面向北、东、南、西。正式采集每向从 12 秒起持续校验，达到 60 条 RSSI 和 3 枚有效信标立即结束，25 秒仍未达标延长到 30 秒，30 秒仍未达标时该方向待补采。对准目标 ±15° 时振动，保持朝向 3 秒后开始采集。罗盘不可用时，按现场参照转向并手动确认。 |
| **T6 静态对比** | 操作同 T4，按静态测试清单采集。记录用于评估，和建库样本分开。 |
| **T7 路线试走（可选）** | 用于熟悉路线和打点。打开「使用候选点试采」，点「开始路线」。走完点「结束路线」，核对打点和路线编号，再点「确认上传」。 |
| **T8 导航与动态对比** | 正式走测统一从这里开始。选择冻结配置和本轮方法，进入地图开始实验导航。经过检查点时打点，经过终点参照线时点「确认实际到达」。系统先判定到达时仍可继续打点和确认。人工先到时在终点等待系统判定，两个状态完成后点「保存本轮」。若仍未判定，点「结束等待并保存」。返回「场记及导出」补传。 |

**跳过当前点**用于暂时无法采集时登记原因。准备倒计时期间可点**取消准备**。录制中需要放弃时，**长按中止**并选原因，已录的部分会留档。若提示本机保存失败，点**重试本地保存**。

T8 的 **A** 用默认参数做三点定位，**B** 用现场标定参数做三点定位，**C** 优先用指纹，未命中时回退 B。回退仍归在 C 轮次，单独统计。

在「静态标定 → T7/T8 路线检查点」查看 P 点测距参照并提前放样。T8 行走时，按按钮显示的「下一点」依次经过 CP 和 P，每到一点都点同一个「打点」按钮。需要测长震时，开始前开启无障碍导航。 [打点顺序、坐标与参照](field-survey.md#t8-提前播报参照点)

## 3. 信标巡检：确认哪些信标有广播

| 按钮 | 怎么用 |
| --- | --- |
| **开始扫描** | 查看名单中各信标的 RSSI 和最后收到的时间。「●」表示最近收到过广播，「○」表示近期未收到。 |
| **点击一枚信标 → 保存巡检记录** | 选择「贴装」「复核」「异常」或「拆除」，补充位置、固定方式或说明，然后保存。 |
| **导出台账** | 导出已上传的巡检记录（CSV）。离线保存的记录先补传，再导出。 |

## 4. 场记及导出：补传、记录和整理结果

| 按钮 | 怎么用 |
| --- | --- |
| **重试上传** | 有「待补传」时，恢复网络后点一次。看到待补传为 0，再导出。 |
| **保存场记** | 填路线编号、检查点编号、观察时刻（`时:分:秒`）或转向评价。也可记录异常，离场时勾选「已清场」。 |
| **导出正式实验 ZIP** | 导出已上传的正式记录，供实验统计。 |
| **导出含试采的 ZIP** | 在正式记录之外包含已上传的试采记录，适合检查流程。 |
| **从正式 T4 数据建库** | 默认勾选当前地图生效的 T4 批次。需要合并数据时，可勾选同一地图下其他已完成的批次。检查四向采集已齐全且上传成功后，确认建库。建库会替换采集楼层的现用指纹，旧版本可回滚。 |
| **冻结当前实验配置** | 应用标定结果并启用指纹库后操作。保存本轮要用的地图、定位参数和指纹库版本。 |
| **重放 A/B/C** | 使用已上传的 T8 路线编号。后台用本轮打点、原始 RSSI 和该轮冻结配置计算三种方法的检查点误差，并列出漏打点位。也可重放历史 T7 记录，T7 需要手动选择冻结配置。 |

ZIP 和巡检台账的文件清单、字段及统计口径见 [现场实验导出数据格式说明](现场实验导出数据格式说明.md)。

首页「采集」里的**静态标定、对数等距、指纹网格**可单独用于找点、测信标和排查覆盖。要把记录计入正式批次，从本页「任务」开始。
