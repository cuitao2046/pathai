## 三、关键技术决策与架构演进

### 解析器架构
- **图层策略**：PyMuPDF OCG 按层提取；`A-TECH-SANT` 整层显式剔除（get_drawings 不感知可见性）。
- **坐标标定**：`SCALE=0.0529 m/pt`、原点 `(2019.1,1154.8)pt`、Y 翻转、`set_rotation(0)` 处理 270° 旋转。
- **门识别四要素**：window 层摆弧（swing/fire）+ DK 矢量笔画（opening）+ 几何墙缝 + 贴墙判定；**DK 不在文本层、是 window 层矢量笔画**，旋转无关 4 方向。
- **房间识别**：OpenCV 栅格化 + 形态学 + 分水岭 + 标签探测；开放/封闭空间分治（垂直合并同类、共域多源测地分割、字号最大者为语义层）。
- **门归属权威判据**：门坐标贴墙房间（<0.6m），**不信任 `rooms` 字段**（geometry.doors rooms 漂移率 38%）。

### 拓扑建模演进
- v9 节点 5 类（room/doorway/intersection/facility/facility_entrance），边带 distance/estimatedTime/accessibilityLevel/riskLevel。
- 开放空间（corridor/lobby/activity/atrium）不建封闭 room 节点，改建 intersection 节点；走廊连通性由 TI↔TI 承担。
- **门节点 TD 生成规则 v9**：同物理开口门按 center_m(0.8m)+投影坐标(1.0m) 两次合并为一个 TD；仅当归属≥1 封闭房间才建 TD，纯走廊通行门不建 TD。
- **门不合并（铁律）**：用户明确同一物理开口只许一扇门，禁用 `dedupe_doorways`/`_merge_nearby_doors` 等任意门合并。
- 跨层边按图纸井道编号配对（matchedBy: code），10 条（楼梯 7 + 电梯 3）。
- 编号规范 `F{floor}-{ABBR}-{seq:04d}`，TF 先楼梯后电梯连续编号，跨层边 `FX-XE-xxxx`。

### 骨架管线
- 手动骨架优先：`skeleton_manual_parsed.json` 存在时跳过 medial-axis，用其 TI/TI-TI/骨架线（含红色无填充矩形以闭合折线存入）；F2 孤岛由 pipeline 软桥补边保 100% 连通。
- 性能：medial_axis 优化（matplotlib 栅格化 / adaptive_resolution / 卷积剪枝）→ 边爆炸修复（TI↔TI 沿骨架邻接）→ TI 图收缩（union-find）→ 连通 100%。
- 依赖：scikit-image + networkx；networkx 3.6 在 Py3.14 有 dataclasses bug，需给 `Config` 补显式 `__init__`。

### 渲染交互演进（render_interactive.py）
- 自包含 HTML：图层开关（23+ 类，含门/普通门/门洞/防火门/电梯门/基础设施独立开关）、缩放/平移（触控板双指）、悬停/点击详情、楼层跳转、拓扑联动高亮、导出所选图层 SVG。

## 四、工程纪律（铁律）

1. **铁律 0 — 禁止直接在 master 工作**（2026-08-09 起）：所有功能/优化/bugfix 一律新分支；改代码前 `git branch --show-current` 确认。
2. **铁律 0b — 一分支一需求**（2026-08-10 起）：不相关改动必须另开分支；同分支多笔提交须同主题。
3. **铁律 — 分支名禁斜杠/反斜杠**（无条件）：沙箱 `.git/refs/heads/` 写带斜杠名静默失败 → unborn 分支 → `git add` 误全暂存；一律连字符 `-`（feature/xxx→feature-xxx）。
4. **铁律 — 完成必做两件事**：记录当日工作日志（append-only）+ push 到当前分支（沙箱无凭据时明确告知用户"待 push"）。
5. **铁律 — 合入的分支默认删除**：本地 `branch -d` + 远端 `push origin --delete` + `git fetch --prune`。
6. **门不做合并**（用户明确）：同一物理开口只许一扇门，禁用一切门合并逻辑。
7. **骨架数据必须入库**：`result/skeleton_manual_parsed.json` 属代码，重生成必须 commit；严禁 `git checkout` 回退成旧版（曾导致渲染缺矩形）。
8. **编辑 `.gitignore` 后必须 `git add` 再 commit**，否则 merge 中静默丢失。
9. **push 凭据**：SSH 通道 `github-cuitao`（`~/.ssh/config` Host + `id_rsa_cuitao`）；remote 须用 `git@github-cuitao:cuitao2046/pathai.git`。重新 clone 后第一件事 `git remote set-url` 改回 SSH（https 需交互凭据、沙箱必败）。
10. **沙箱 git 禁忌**：禁 `git stash`（refs 写入失败 + index 搞乱）；fetch 后须 `git for-each-ref` 验证 refs 落盘；`git rm -f`/`git checkout -b` 在异常 index 上会误删文件，恢复用 `git archive <commit>`。
