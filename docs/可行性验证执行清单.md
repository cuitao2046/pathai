# AEGIS 可行性验证执行清单

> 目标：用同一批现场采集数据，分别统计 **A 默认配置 / B 静态标定配置 / C 指纹网格** 在准确性与时效性上的表现，分析三者差异，给出方案优劣排序与适用条件；本阶段不设绝对阈值判定。
> 范围原则：采集开始后冻结被测算法；本轮只补测量与汇总能力，不做定位改进。
> 更新日期：2026-11-20

## 一、被测对象与冻结规则

| 编号 | 配置 | 实现 | 评价内容 |
|---|---|---|---|
| A | 默认配置 | 三点定位，内置 `-71 dBm / n=2.0` | 准确性、时效性 |
| B | 静态采集标定配置 | 三点定位，CAL 拟合参数 | 准确性、时效性 |
| C | 指纹网格 | 指纹匹配，失败回退 B | 准确性、时效性、回退率 |

冻结规则：

- [ ] 采集开始后不再修改定位匹配、导航推进、语音播报逻辑。
- [ ] 记录并归档本次实验的 app 版本、地图版本、指纹库版本、参数版本。
- [ ] 所有算法变体仅在离线重放层出现，不影响在线链路。

## 二、阶段 0：统计口径与对比规则（先于代码）

阶段 0 不设“通过/不通过”的绝对标准，只解决三件事：统计哪些指标、样本怎么纳入、三者怎么排序。目的是避免数据出来后临时换指标或挑样本。

- [ ] **T0.1 定义统计指标**
  - 原则：所有指标必须能从现有采集数据 + 代码打点算出，不新增人工记录；否则不纳入。
  - 准确性：平均误差、P90、P95、最大误差、楼层正确率。
  - 可用性：有效定位率、C 回退率、位置跳变次数。
  - 时效性：位置更新间隔、定位请求 RTT、转向播报/震动时序、到达检测延迟。
  - 指标固定为上述集合，后续不因结果好看与否增删。
- [ ] **T0.2 固定被测对象**：确认 A/B/C 三臂参数与版本，写入实验配置并冻结。
- [ ] **T0.3 定义纳入规则**
  - trial / suspect / aborted 段是否纳入。
  - C 回退样本（source=trilateration）如何计入准确性（建议计入，并单列回退率）。
  - 缺失朝向或缺失检查点的处理方式。
  - 全体样本与仅命中样本必须同时输出，不得只报后者。
- [ ] **T0.4 定义对比与排序规则**
  - 每个指标先独立排序，不合成单一分数（避免任意权重）。
  - 综合优劣用 Pareto 支配：某方案在全部指标不劣且至少一项更优，才判为更优。
  - 互有胜负时按维度（准确性 / 可用性 / 时效性）输出条件性排序。
  - 配对差异的置信区间包含 0 时，视为同档，不强行排序。

验收：指标清单、纳入规则、排序规则形成书面记录，后续不再调整。

## 四、阶段 2：预试（trial 数据跑通）

- [ ] **T2.1 全链路试跑**：用 trial 段产出 A/B/C 三张准确性表与时延表。
- [ ] **T2.2 质量检查**：重合点告警、缺失段清单、C 回退原因分布。
- [ ] **T2.3 冻结代码**：打 tag，正式采集期间不再改动定位与导航代码。

验收：预试无阻塞项；同一份数据重复分析结果一致。预试不通过不进入正式采集。

## 五、阶段 3：正式采集

- [ ] **T3.1 T6 静态**：18 点 × 4 朝向，A/B/C 重放评估。
- [ ] **T3.2 T8 动态**：27 轮 × 12 检查点，A/B/C 轮转在线。
- [ ] **T3.3 数据质量门**：完成率、缺失清单、异常段复核后封存数据。

验收：各臂样本量达标；导出 ZIP 完整，manifest 版本与实际一致。

## 六、阶段 4：分析与结论

- [ ] **T4.1 准确性配对比较**：A vs B、B vs C、A vs C，报告均值差、P90 差、bootstrap 置信区间、Wilcoxon 结果。
- [ ] **T4.2 时效分解**：扫描窗口、网络 RTT、服务端处理、更新间隔分列，避免把 2 s 扫描窗口计为算法延迟。
- [ ] **T4.3 三者对比与排序**：按 T0.4 规则输出单指标排序、Pareto 支配关系与按场景的条件性排序；差异不显著标为同档。
- [ ] **T4.4 结论报告**：三者优劣与适用条件、各自的失败模式（回退率、错走廊、位置跳变）以及后续改进方向。

统计注意：检查点嵌套在各轮内，不能当独立样本；按轮聚合或使用混合效应模型，并报告效应量与置信区间。

## 七、本轮明确不做

以下条目已确认不属于本轮可行性验证，待结论出来后再按失败模式立项：

- WKNN / KNN 匹配。
- 缺失信标惩罚、出现率、std 加权。
- 按朝向建库与朝向匹配。
- 地图匹配、可达性约束、平行走廊消歧。
- 卡尔曼滤波、IMU 融合、速度门控、置信度改造。
- 查询缓存与性能优化。
- 0.5 m 网格。
- 环境/时段稳定性分层。

## 八、风险与应对

| 风险 | 应对 |
|---|---|
| C 回退率过高，导致对比失真 | 全体样本与仅命中样本两视图并列；回退率单独列出，不中途调参 |
| 无绝对阈值导致结论主观 | 预先固定指标与排序规则；用置信区间与 Pareto 支配约束结论 |
| ST 点与 FP 点重合导致精度虚高 | T1.2 挂起库，并报告最小距离 |
| 时效被 2 s 扫描窗口主导 | 分层报告端到端与计算耗时，结论注明瓶颈在感知层 |
| 样本相关性导致显著性虚高 | 按轮聚类或混合效应，报告效应量与 CI |
| 采集期间代码变更破坏可比性 | T2.3 打 tag 冻结 |
