针对 CAD PDF 导出的 GeoJSON 矢量数据（含墙线 `WALL`、门洞 `DOOR_FIRE`/`window` 等），提取走道、门厅、大厅等公共空间并生成室内导航拓扑图，高效的算法流程通常基于**负空间分析（Negative Space Analysis）**与**中轴线提取（Medial Axis Transform）**。

以下是完整的算法架构与步骤实现蓝图：

---

### 一、 整体算法流程

算法分为四个核心阶段：

```
[GeoJSON 线段与门洞数据] 
       │
       ▼
 1. 几何修复与面域化 (Polygonization)  ──► 得到封闭空间多边形集合
       │
       ▼
 2. 负空间差值与公共空间识别          ──► 过滤出走道、大厅等公共空间多边形
       │
       ▼
 3. 骨架提取与图形剪枝 (Skeleton/MAT)   ──► 生成公共空间中心轴线网格
       │
       ▼
 4. 拓扑节点与边映射 (Topology Graph) ──► 输出标准拓扑点 (TI/TD/TR/TEN/TE)

```

---

### 二、 核心算法步骤详解

#### 1. 几何修复与平面多边形化 (Planar Polygonization)

CAD 导出的墙线 `LineString` 常存在微小缝隙或未完全闭合的情况。

* **墙线容差捕捉 (Snapping & Line Merge)**：使用容差 $\epsilon$（如 $0.05\text{m} \sim 0.1\text{m}$，按 `scale: 0.0529` 计算转换）对所有墙线节点进行吸附与合并。


* **线串构面 (Polygonize)**：将修复后的墙线与建筑外轮廓线放入平面直线图（PSLG）结构中，通过线段相交切割生成基础面元（Faces）。

#### 2. 公共空间识别与分类算法 (Public Space Filtering)

公共空间（走道、大厅、门厅）在几何与拓扑上具有显著的负空间特征：

* **差值提取法 (Negative Space Extraction)**：
如果 GeoJSON 已包含已知房间（`RM`），公共空间多边形 $P_{public}$ 可通过楼层总边界 $P_{floor}$ 扣除所有实体墙体缓冲区与已知房间得到：



$$P_{public} = P_{floor} \setminus \left( \bigcup P_{room} \cup \text{Buffer}(W_{wall}, \delta) \right)$$


* **几何与拓扑特征判定**（适用于无标记房间时自动分类）：
对构建出的每个空间多边形计算以下特征指标：
1. **长宽比 / 狭长度 (Aspect Ratio)**：

$$AR = \frac{L_{max}}{W_{eff}} = \frac{\text{BoundingBox.Length}}{\text{Area} / \text{BoundingBox.Length}}$$


* **走道 (Corridor)**：$AR > 3.0$（高度狭长）。


2. **门洞连接度 (Door Count & Openness)**：
统计多边形边界相交或临近的门洞（摆弧门 `swing`、防火门 `fire`、无摆弧开口 `opening`）数量 $N_{door}$。


* **门厅/大厅 (Lobby/Atrium)**：$N_{door} \ge 3$ 且面积 $Area > A_{threshold}$，或者包含多个 `opening` 无摆弧开口。




3. **凸包率 (Convexity)**：

$$\text{Convexity} = \frac{\text{Area}(P)}{\text{Area}(\text{ConvexHull}(P))}$$


* **复杂通廊/凹多边形**：Convexity 较小（通常 $< 0.6$）。





#### 3. 中轴线提取与骨架剪枝 (Skeletonization & Graph Pruning)

为公共空间多边形提取导航网格：

1. **受约束沃罗诺伊图 (Constrained Voronoi Diagram, CVD) / 直骨架 (Straight Skeleton)**：
在公共空间 $P_{public}$ 内部密集采样边界点，生成内部 Voronoi 边线。
2. **骨架剪枝 (Dangle Pruning)**：
Voronoi 图会产生指向多边形死角/凸角的冗余分支。必须移除末端度数为 1 且未连接到门洞或出入口（`TEN`） 的悬挂分支。



#### 4. 关键拓扑点与边生成 (Topology Generation)

根据规范定义，将几何中轴线转换为标准拓扑元素：

| 拓扑对象类型 | 编号缩写

 | 生成逻辑 |
| --- | --- | --- |
| **拓扑交叉口节点** | `TI`<br> | 中轴线网格中**度数 $\ge 3$ 的分支交叉点** |
| **拓扑门口节点** | `TD`<br> | 门洞几何（`swing`/`fire`/`opening`）中心点垂直投影至中轴线的节点

 |
| **拓扑房间节点** | `TR`<br> | 房间多边形（`RM`） 的形心/质心

 |
| **拓扑出入口节点** | `TEN`<br> | 外墙无摆弧开口或楼梯/电梯接口处的中心点 |
| **拓扑设施节点** | `TF`<br> | 无障碍设施/特定服务设施点

 |
| **拓扑边** | `TE`<br> | 连接 `TI-TI`、`TI-TD`、`TD-TR` 的几何中心线段 |

import networkx as nx

def extract_public_spaces_and_topology(geojson_data, floor_str="1"):
    floor_geom = geojson_data["floors"][floor_str]["geometry"]
    
    # 1. 提取所有墙线并进行合并与容差修补
    wall_lines = []
    for w in floor_geom.get("walls", []):
        coords = w["geometry"]["coordinates"]
        wall_lines.append(sg.LineString(coords))
    
    merged_walls = unary_union(wall_lines)
    
    # 2. 面域化 (Polygonize)
    faces = list(polygonize(merged_walls))
    
    public_spaces = []
    
    # 3. 筛选公共空间 (以长宽比 AR 和面积为例)
    for face in faces:
        area = face.area
        bbox = face.minimum_rotated_rectangle
        # 获取外接矩形的长宽
        rect_coords = list(bbox.exterior.coords)
        edge_lens = [
            sg.Point(rect_coords[i]).distance(sg.Point(rect_coords[i+1]))
            for i in range(len(rect_coords)-1)
        ]
        length, width = max(edge_lens), min(edge_lens)
        
        ar = length / (width + 1e-6)

### 四、 性能优化与工程细节建议

1. **空间索引（R-Tree）**：
在计算门洞（`D`）到走道中轴线的投影与吸附时，使用 `rtree` 或 Shapely 的 `STRtree` 进行碰撞检测与最近邻检索，复杂度可从 $O(N^2)$ 降至 $O(N \log N)$。


2. **跨层拓扑衔接（`XE` / `ST` / `EL`）**：
楼梯（`ST`）与电梯（`EL`）产生的拓扑节点需标记为跨层节点，并在 `FX`（跨层）层级生成跨层边 `XE`，连接首层 `F1` 与二层 `F2` 的 `SR`（楼梯风险节点）或 `EA`（无障碍电梯节点）。


3. **针对 CAD 几何特性的例外处理**：
对于无摆弧开口 `opening`，在差值计算时需视其为**完全通畅的虚拟边界**，避免将连通的“走道-大厅”区域误切割为孤立多边形。
