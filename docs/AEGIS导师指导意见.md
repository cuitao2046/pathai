# 导师指导意见

项目名称：基于空间语义与大模型驱动指导的视障智能手机辅助室内导航系统（AEGIS）

申请人：崔刘沛阳　　学校及班级：北京中学国际部高二（1）班

该课题面向视障辅助导航需求，融合空间语义建图、蓝牙定位与智能交互，具有研究价值。学生已形成结构化地图及小程序原型，具备开展现场实证的基础。

本阶段检验信标布局、定位精度与系统稳定性，所需技术数据可由普通在校人员按统一规程采集，校内缺少视障人士不影响该阶段研究。目标用户体验与通行安全性留待后续专项验证。学校具备CAD图纸及典型建筑空间，便于真值核验、控制变量和重复测试，是适合本阶段研究的场地。

本人明确支持该项目立项，建议学校批准在指定区域临时部署56枚信标并开展测试。我将重点指导实验设计、数据分析与论文撰写，督促学生如实报告结果、遵守学校管理要求，测试结束后完成设备撤除与场地恢复。
