# 25 - 第二阶段小程序客户端联调与真机检查清单

> 适用：`client/` 原生 TypeScript 微信小程序工程（第二阶段 C0-C8 交付物）。
> 契约权威：`docs/24-第一阶段前后端需求与API定义.md`。

## 1. 本地联调环境（开发者工具）

### 1.1 后端启动

```powershell
# 仓库根目录；首次需建库（本地 SQLite：backend/.local/pathai.db）
cd d:\code\pathai\backend
$env:PATHAI_ENV='local'
$env:PATHAI_WECHAT_FAKE='1'        # fake 登录：code 以 fake-<openid> 直换
$env:PATHAI_OPENID_SALT='local-dev-salt'
$env:PATHAI_DATABASE_URL='sqlite:///D:/code/pathai/backend/.local/pathai.db'
python -m alembic upgrade head
# --host 0.0.0.0：真机（局域网 IP）必须能连；默认只绑 127.0.0.1 手机连不上
python -m uvicorn "pathai_backend.app:create_app" --factory --app-dir backend --host 0.0.0.0 --port 8000
```

注意事项：

- 若残留 **M0 旧 schema 数据库**（`alembic_version=0001_initial`，含 users 表）会报
  `Can't locate revision`，删除 `backend/.local/pathai.db` 重建即可（本地开发数据可丢弃）。
- PATHAI_WECHAT_FAKE 仅允许 env=local；上线/演示环境必须关闭。
- 真机联调需放行 **Windows 防火墙 8000 端口入站**（Python/uvicorn 首次监听时按提示勾选专用网络即可）。

### 1.2 小程序端开关（client/config/env.ts）

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| `API_BASE_URL` | `http://192.168.68.108:8000` | 开发机 WLAN IP；手机与电脑须同一 WiFi，DHCP 换网后 IP 漂移需同步修改 |
| `DEFAULT_DATA_SOURCE` | `'mock'` | 开发者工具无 iBeacon，用模拟轨迹 |
| `DEBUG_REWRITE_DATA_URL` | `true` | dataUrl 重写为 API 同源（sha256 校验不关闭） |
| `WECHAT_FAKE_LOGIN` | `true` | wx.login code 加 `fake-` 前缀配合后端假登录；**上线前必须改 false** |

- 开发者工具需勾选「不校验合法域名」（详情 → 本地设置）。
- **真机**上访问 http://局域网IP 同样需放行域名校验：预览/真机调试打开手机端
  「开发调试」（右上角胶囊 → 开发调试，开启后重启小程序），否则报
  「不合法的域名」或 NETWORK_ERROR「网络连接不可用」。
- 数据源可在 **设置页** 切换（mock/live，写本地存储，重启小程序生效）。
- ⚠️ **「微信同声传译」插件仅对企业/组织主体开放**（插件类目「IT科技>软件服务提供商」，
  个人主体在后台搜不到也无法添加，官方社区已确认）。当前主体为个人 → app.json 不声明
  `plugins.WechatSI`，**live 数据源的按住说话录音/识别不可用**（PTT 报识别失败属预期）；
  mock 数据源下 PTT→意图→导航全链路不受影响。主体变更为企业/组织后：后台按 AppID
  `wx069ba97219f66d99` 添加插件 → app.json 恢复 plugins 声明（version 0.0.7）。

### 1.3 已验证的端到端链路（2026-10-25）

后端 fake 模式下模拟客户端完整 API 流程，全部通过：

```
API-01 登录(fake code) → API-02 摘要(ETag) → 地图包(sha256)
→ API-04 意图「带我去一楼图书馆」→ API-05 定位(reliable conf=0.97)
→ API-06 建会话(Idempotency-Key，重放同会话) → API-07 更新(instruction)
→ API-07 更新(arrived) → 终态拒更新(409) → API-09 end 到达后(409) → API-09 取消(ended)
```

样例地图注意：路线总长仅 5m，`ARRIVAL_RADIUS_M=5.0`——
**到达半径内坐标（如走廊节点 (5,5) 距图书馆 (5,10) 恰 5m）一拍即到达**；
测试非到达更新须用距终点 >5m 的坐标（如 (5,2)）。

### 1.4 开发者工具人工联调步骤

1. 打开 `client/` 工程 → 编译；
2. 首页等待「地图已就绪」→ 按住说话 → 说「带我去图书馆」（或用 mock 调试输入框）；
3. 意图回复 + TTS 播报（mock 引擎立即完成）→ 点「开始导航」；
4. 导航页：mock 轨迹自动定位 → 创建会话 → 播首条指令 →「导航中」；
5. 结束：双击「结束导航」→ 返回首页。

### 1.5 端侧 ASR（Sherpa-Onnx WASM）验收 — live 数据源

前置：后端运行中（含 `/static/asr` 静态路由与 `backend/static/asr/` 模型文件）、
设置页数据源切 **live** → 重启小程序。

1. **模型下载（首启一次，此后零联网）**：vConsole 应见
   `[asr-model] 下载中 …` → `校验通过` ×3 → `ASR 模型就绪`；
   断网重试：直接再进（有就绪标记后不再联网）；
2. **运行时就绪**（app-context 预热，warmup）：vConsole 见
   `[sherpa] wasm 运行时就绪` → `在线识别器创建完成（zipformer2 CTC zh int8）`；
3. **按住说话**：录音中说「带我去资源教室」→ 松手 → 中间结果（partial，
   0.5s 节流）与最终文本回显 → 意图解析闭环；
4. **离线验收（核心目标）**：模型就绪后开**飞行模式** → 冷启动 →
   地图缓存秒开 → PTT 识别 → 意图 → 导航全链路照常；
5. **分包完整性**：工具上传清单 `subpackages/asr` 应含
   `sherpa-onnx-wasm-main-asr.wasm`（13.15MB）+ 两份 cjs；
6. 真机差异项：iOS PCM `onFrameRecorded` 裸样本核实（若异常：剥 RIFF 头
   走 tempFilePath 备选）、SIMD 需微信 ≥8.0.25、30s 录音上限自动停并出文本；
7. Node 侧同产物冒烟（与小程序同一套 patch 文件）：
   `node scripts/asr-node-smoke.js` → `SMOKE OK`。

已知边界：live 的 **TTS 仍走同声传译**（个人主体无插件）→ 播报降级为
震动+屏幕文本（FE-04 预期行为）；CTC 质量若导航指令识别不达标 → 升级
候选 B 模型（43.3MB int8 三件，改 `ASR_MODEL_VERSION` + `backend/static/asr`）。

## 2. 真机联调检查清单

### 2.1 iBeacon 硬件与扫描

- [ ] 信标广播三元组（UUID/Major/Minor）与地图包登记一致（大小写不敏感）；
- [ ] `txPower` 与现场实测对齐（解算模型 `d = 10^((txPower-rssi)/20)`）；
- [ ] **安卓系统「定位服务」开关必须打开**，否则扫描不到信标（无需申请 wx.getLocation 权限）；
- [ ] iOS 需在 app.json 已声明 `requiredBackgroundModes` 不必要——前台扫描即可；
- [ ] 设置页切 live 数据源 → 重启小程序 → 导航页定位 quality 应为 reliable/degraded。

### 2.2 微信同声传译插件（WechatSI）

- [ ] 小程序管理后台「设置 → 第三方设置 → 插件管理」添加「微信同声传译」并审核通过；
- [ ] `app.json` 声明插件与 provider（当前工程用微信同声传译插件，live 模式加载）；
- [ ] 在后台「开发 → 开发管理 → 接口设置」确认 plugin 权限；
- [ ] 配额：免费额度按日限流，压测时注意 TTS/ASR 失败日志；
- [ ] TTS 失败路径：设置页「语音自检」失败时应看到文字降级提示（FE-04）。

### 2.3 生命周期与音频中断

- [ ] 导航中切后台：采集停止（onHide → handleBackground）；
- [ ] 回前台：先查询会话（API-08）校验 status/mapVersion → 恢复采集 → 重播当前指令（FE-05）；
- [ ] 后台期间服务端已 ended/arrived：回前台应收敛 UI 并停止采集；
- [ ] 锁屏再解锁：同切后台路径；
- [ ] 音乐/电话打断 TTS：微信同声传译插件 onStop/onError 回调 → 队列降级路径。

### 2.4 隐私与合规（后台「用户隐私保护指引」）

需声明的收集项与用途（**不含位置信息**）：

- [ ] 蓝牙：扫描 iBeacon 信标用于室内定位；
- [ ] 麦克风：按住说话时的语音识别；
- [ ] 加速度传感器、陀螺仪传感器、磁场传感器、设备方向传感器：航向估计（第一阶段仅预留）；
- [ ] 不声明「位置信息」：定位由信标解算在后端完成，不使用 wx.getLocation。

### 2.5 真机回归（最小集）

- [ ] 登录 → 地图 → 意图 → 导航 → 到达 全流程（live 数据源 + 真实插件）；
- [ ] 偏航触发 reroute：人为走到路线外 >8m（OFF_ROUTE_M），应播新路线首条；
- [ ] 遮挡信标触发 relocalizing：safety 播报一次 + 长震动，恢复后继续；
- [ ] 到达播报：高置信度「已到达目的地。」/ 低置信度「已到达目的地附近…」；
- [ ] 弱网（开发者工具 Network 设 Slow 3G）：更新超时不阻塞，下一拍续传。

## 3. 已知边界（第一阶段范围）

- 阈值常量（txPower、OFF_ROUTE_M、ARRIVAL_RADIUS_M 等）为工程初始值，须现场标定后冻结；
- `estimatedDurationSec` 后端恒为 null；
- recovering 态回前台后仍由服务端 UPDATE_RESULT 决定是否恢复采集（客户端不自行重启）；
- 引擎自检仅覆盖 TTS 播报；ASR 自检依赖真实语音输入，留在真机人工步骤。
