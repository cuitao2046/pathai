# 关于在北中高中国际部教学楼部署蓝牙信标、验证视障人士室内导航技术方案的申请

尊敬的学校领导：

您好！我正在开展中学生科技创新研究课题——"视障人士室内导航系统（PathAI）"（英才计划项目，总体技术路线已与指导教师沟通确认）。为保证课题按计划推进，现申请在学校教学楼公共区域部署少量蓝牙信标用于技术验证，有关情况说明如下，恳请学校审核批准。

## 一、项目为什么需要部署蓝牙信标

本项目是一套面向视障人士的室内导航系统：视障人士携带手机运行导航小程序，由系统通过语音实时引导其在建筑物内安全通行。室外导航依赖卫星定位，但卫星信号无法穿透建筑物，在室内基本失效——因此室内导航必须自建定位基础设施，这正是蓝牙信标在本方案中的核心作用。

蓝牙信标相当于"室内的定位基准点"：它们只有火柴盒大小，像一座座微型信号灯塔，固定安装在走廊、楼梯口、电梯厅、转角等位置，持续发出低功率蓝牙信号；使用者手机通过接收周边多个信标的信号强度，实时解算出"我在哪里"（普通区域精度约 2~5 米，楼梯、门口等关键节点可达 1~2 米），系统再据此生成语音引导，例如"前方 12 米到达走廊交叉口，请左转"。

因此，蓝牙信标是整个系统的定位地基：没有它，路径规划、语音播报、安全提醒都无从谈起。本项目需要论证的核心技术问题——信标布设的位置与密度、实际能达到的定位精度、能否支撑视障人士安全通行——都只能在真实部署环境中实测获得。这也是与指导教师确认后的既定技术路线。

## 二、为什么暂不使用商场、医院作为验证场地

本项目视障导航的目标应用场景确实是商场、医院等大型公共空间，但**当前阶段的目标是论证技术方案的可行性**，尚不属于落地实施阶段。若直接进入商场、医院验证，将首先面临大量非技术层面的挑战：

1. **场地协调难以达成。** 商业与医疗场所的物业没有义务配合个人研究项目，进场部署需物业、商户/科室、安保等多方同意并落实安全责任，一般情况下很难获准；
2. **数字地图工程量巨大。** 将这类环境数字化为可导航地图，强依赖建筑物设计图纸和较为复杂的图纸处理程序研发；商业楼宇图纸通常无法获取，该工程量远超个人研究项目的能力范围；
3. **设施部署与采集成本高。** 商场结构复杂（中庭、店铺分隔、扶梯、停车场等），同等验证所需的信标数量与现场采集工作量，个人研究项目难以覆盖；
4. **实施周期长。** 进场审批、错峰施工与联调验收会显著拉长周期，与课题研究的时间窗口不匹配。

若坚持在商场验证，项目很可能停留在纸面方案、无法获得任何实测数据，反而失去研究的意义。

## 三、为什么教学楼是合适的验证场地

北中高中国际部教学楼是一个非常好的替代验证场地：

1. **安装安全、无损伤。** 信标采用 3M 建筑双面胶粘贴于距地约 2.8 米的墙面高处（完全在人头顶以上），不打孔、不布线、不改动建筑结构与任何设施，不影响教学楼的美观与正常使用功能，日后可完整取下、基本不留痕；
2. **空间与结构要素足够。** 教学楼走廊、楼梯间、电梯厅、转角与各类房间门等要素，与商场/医院的室内通行结构同构，空间规模足以支撑完整测试路线，可全面验证"信标部署 → 实时定位 → 无障碍路径规划 → 语音播报"全链路技术方案；同时本项目已基于教学楼建筑图纸完成了楼层导航地图的构建，这一"图纸 → 数字地图"流程在商场场景同样适用；
3. **成本可控。** 在此范围内部署约 60~70 枚信标（含备件），材料成本在学生研究项目可承受范围内；同类验证若放到商场，规模与成本将放大一个数量级以上；
4. **便于模拟测试。** 视障导航研究需要大量"蒙眼模拟视障人士"的实地测试，校内场地安全可控，便于安排指导教师与同学协助，测试可安排在课后进行。

此外，若本方案验证成功，系统可直接用于校内视障师生与访客的日常通行引导，研究成果可以直接回馈校园。

## 四、安装方式与安全保障承诺

1. 全部信标采用 3M 建筑双面胶**免打孔**安装，安装前向学校提交点位清单，位置避开消防设施、疏散指示等设备；
2. 安装、调试与数据采集均安排在放学后或周末进行，避开教学与考试时段，不影响正常教学秩序；
3. 信标为低功率蓝牙广播设备（发射功率低于一部手机的蓝牙），纽扣电池供电，对人体无影响，不干扰学校 Wi-Fi、广播等系统；
4. 每枚信标统一编号、登记造册；项目结束后拆除全部信标并清理残胶，恢复墙面原状；
5. 现场拍摄与数据采集遵守隐私规范：事先报备、避开师生，涉及人像的内容不作项目外使用。

## 五、申请事项

恳请学校批准本人在**北中高中国际部教学楼 1~2 层公共区域**（走廊、楼梯间、电梯厅、门厅等，不涉及教室内部）部署约 60~70 枚蓝牙信标，用于"视障人士室内导航系统"课题的技术验证。本人可随时提供信标点位图、设备说明与材料清单，并接受学校后勤等部门对安装与测试过程的监督指导。

恳请学校批准为盼！
