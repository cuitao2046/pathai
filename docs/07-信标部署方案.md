# PathAI 室内导航系统 · 信标部署方案

> **信标部署应以"决策节点"而不是简单的均匀覆盖为原则，重点覆盖安全节点和导航决策点。**

## 一、信标选型标准

### 1.1 核心技术要求

| 要求项 | 规格 | 说明 |
|--------|------|------|
| 蓝牙版本 | BLE 5.0 | 微信小程序蓝牙适配器要求 BLE 4.0+ |
| 协议支持 | iBeacon + Eddystone | 双帧兼容性更好 |
| 广播间隔 | 100~300ms 可配置 | 兼顾精度与续航 |
| 发射功率 | -12~+4 dBm 可调 | 适应不同覆盖场景 |
| 电池续航 | 3 年以上 | 减少维护成本 |
| 防护等级 | IP65 | 室内环境足够 |

### 1.2 推荐芯片方案

| 档次 | 芯片方案 | 协议 | 参考单价 | 适用性 |
|------|---------|------|---------|--------|
| 最低配 | NRF51822 / DA14580 | iBeacon | ¥15~25 | 满足基本需求，注意 NRF51822 仅支持 BLE 4.2，不满足选型表中的 BLE 5.0 要求，仅限预算极度受限时采用 |
| 推荐配 | nRF52810 / nRF52832 | iBeacon + Eddystone | ¥25~40 | 双帧兼容性更好 |
| 中端配 | nRF52832 + 传感器 | iBeacon + Eddystone + TLM | ¥40~80 | 带遥测帧，可远程监控 |

**推荐选择**：nRF52832 方案，原因：
- 支持 iBeacon 和 Eddystone 双帧广播
- 参数可通过手机 APP 修改，灵活匹配数据库台账
- 是目前室内导航部署中最主流的芯片方案
- 稳定性和兼容性经过大量验证

### 1.3 采购渠道

- **国内首选**：1688 和京东上的深圳信标厂商（微能信息 95Power、铂礼、嘉之栋等）
- **国际可选**：MOKOSmart、Minew、Kontakt.io（价格更高，不建议课题项目采用）
- **采购策略**：先买 5~10 个样品做功能验证，确认稳定扫描后再批量采购

## 二、部署原则

### 2.1 决策节点优先

信标部署遵循"决策节点优先"原则，而非均匀覆盖。重点部署位置包括：

- 建筑入口和出口
- 楼梯与扶梯两端
- 电梯厅
- 长走廊的转角
- 交叉路口
- 重要房间门口
- 服务台
- 无障碍卫生间
- 商场主通道与停车场连接处
- 医院挂号、缴费、取药和检查区域

### 2.2 分层部署策略

#### 普通区域

- 走廊段每 8~12 米布一个信标
- 定位精度约 2~5 米

#### 关键节点

- 关键转角和门口：通过密集信标提升到约 1~2 米
- 信标间距缩小到 3~5 米

#### 视障模式增强

- 在楼梯、扶梯、电梯、门口和道路交叉点增加信标密度
- 结合手机陀螺仪、加速度计和电子罗盘进行航向修正
- 安全节点区域必须加密部署

## 三、高风险节点部署方案

### 3.1 楼梯与扶梯

楼梯与扶梯是视障导航的最高风险区域，部署密度必须最高：

```
    [预警信标]    ← 距入口 3~5 米，提前 2~3 秒播报安全提示
        |
    [入口信标]    ← 楼梯/扶梯入口处
        |
    [出口信标]    ← 楼梯/扶梯出口处
```

**部署要求**：
- 楼梯与扶梯两端入口各布一个信标
- 距入口 3~5 米处增设预警信标
- 确保系统在用户接近时能提前预警

### 3.2 电梯厅

电梯是视障用户的主要垂直通道，需要精确引导：

```
[厅入口信标] → [电梯口信标] → [厅内信标]
```

**部署要求**：
- 电梯厅入口处布一个信标
- 每个电梯门口布一个信标
- 厅内中央布一个信标

### 3.3 走廊交叉口

交叉口是路径决策点，需要多方向覆盖：

```
        [北向信标]
           |
[西线信标] ---交叉口--- [东线信标]
           |
        [南向信标]
```

**部署要求**：
- 交叉口四个方向各布一个信标
- 确保用户在任何方向接近都能被检测到

### 3.4 玻璃门与旋转门

```
[门侧信标] ---门--- [门侧信标]
```

**部署要求**：
- 玻璃门与旋转门两侧各布一个信标
- 触发高优先级安全预警

### 3.5 建筑出入口

```
[室外信标] ---入口--- [室内信标]
```

**部署要求**：
- 建筑出入口内外各布一个信标
- 室内信标作为导航起点
- 室外信标作为入口预警

## 四、信标参数配置

### 4.1 广播参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 广播间隔 | 200ms | 兼顾精度与续航 |
| 发射功率（开阔走廊） | -8 dBm | 覆盖半径约 8~10 米，与 8~12 米布点间距匹配，保证任意位置可见 2 个以上信标 |
| 发射功率（密集节点区域） | -12 ~ -8 dBm | 覆盖半径约 3~5 米。密集区域应**降低**功率以缩小信标间信号重叠，提升指纹区分度；高功率会扩大覆盖重叠、模糊 RSSI 向量差异，反而降低定位精度 |
| UUID | 场馆维度统一 | 便于识别场馆 |
| Major | 楼层维度 | 便于定位楼层 |
| Minor | 节点维度 | 标识具体位置 |

### 4.2 编码规范

每个信标配置全局唯一 UUID/Major/Minor：

```
UUID: B9407F30-F5F8-466E-AFF9-25556B57FE6D  (场馆维度)
Major: 1 (1楼) / 2 (2楼) / ...
Minor: 101 (入口) / 102 (转角) / 103 (交叉口) / ...
```

## 五、信标台账管理

### 5.1 台账字段

每个信标部署后立即录入信标台账库，字段包括：

| 字段 | 说明 | 示例 |
|------|------|------|
| 信标 ID | 全局唯一编号 | BK-01-001 |
| UUID | iBeacon UUID | B9407F30-F5F8-... |
| Major | 楼层标识 | 1 |
| Minor | 节点标识 | 101 |
| 坐标 | 安装位置坐标 | (4.0, 24.0) |
| 楼层 | 所在楼层 | 1 |
| 安装位置描述 | 文字描述 | "1楼主入口" |
| 安装高度 | 安装高度（米） | 2.5 |
| 发射功率 | dBm | -8 |
| 广播间隔 | ms | 200 |
| 电池型号 | 电池规格 | CR2477 |
| 预期续航 | 年 | 3 |
| 覆盖语义标签 | 功能标签 | "入口""交叉口" |
| 安装日期 | 部署日期 | 2026-08-01 |

## 六、信标监控与维护

### 6.1 在线状态监控

系统定期（每 5 分钟）扫描场馆内信标广播，与台账比对：

- 发现离线信标立即告警
- 监控页面展示信标列表、在线状态、电池电量估算和最后心跳时间
- 告警通知通过邮件/短信发送给运维人员

### 6.2 电池电量监控

通过 BLE 遥测帧（TLM）获取电池电量：

- 电量 < 20%：预警通知
- 电量 < 10%：紧急通知
- 定期生成电池更换计划

### 6.3 信号异常检测

监控信号异常情况：

- 信号强度突然变化：可能遮挡或移位
- 广播频率异常：可能电池问题
- 位置漂移：可能被移动

### 6.4 维护周期

| 维护项 | 周期 | 说明 |
|--------|------|------|
| 在线状态检查 | 每 5 分钟 | 自动化监控 |
| 电池电量检查 | 每周 | 生成报告 |
| 信号强度抽检 | 每月 | 现场巡检 |
| 台账数据更新 | 每季度 | 核对物理状态 |

## 七、典型教学楼部署估算

### 7.1 面积估算

以北京中学教学楼为例：

| 估算项 | 中值估计 |
|--------|---------|

按"走廊长度 + 决策节点"计算：

| 部署位置 | 每层数量 | 4 层合计 | 占比 |

| 走廊通道 | 17 | 68 | 45% |

| 电梯·无障碍设施 | 4 | 16 | 11% |
| 冗余覆盖 | — | 20 | 13% |
| **合计** | **33** | **152** | **100%** |

### 7.3 预算估算

| 方案 | 单价 | 152 个总价 | 特点 |
|------|------|-----------|------|
| 最低配 | ¥20 | ¥3,040 | 参数固定 |

## 八、部署验收标准

| 验收项 | 标准 | 检验方法 |
|--------|------|---------|
| 信标在线率 | ≥ 98% | 系统监控数据 |
| 安全节点覆盖率 | 100% | 逐点检查 |
| 台账与物理对应 | 100% | 现场核对 |
| 信号覆盖连续性 | 盲区 < 5% | 路测检查 |
| 定位精度达标 | 视障模式（安全节点周边）中位误差 < 1 米；普通区域 < 2 米 | 实测验证 |
