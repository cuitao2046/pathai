# PathAI 室内导航系统 · 信标部署方案（通用方法论）

> **本文档定位**：室内 BLE 信标部署的**通用方法论**——选型标准、部署原则、高风险节点部署、参数配置、台账管理、监控维护与验收标准，不绑定具体建筑。
>
> **项目落地请见**：[`docs/08-信标部署与指纹采集实施方案.md`](08-信标部署与指纹采集实施方案.md)——以初中 1# 教学楼 1~2 层为例的完整实施方案（含指纹定位 / 三点定位两套体制的采购清单、预算与施工日程）。
>
> 核心原则：**信标部署应以"决策节点"而不是简单的均匀覆盖为原则，重点覆盖安全节点和导航决策点。**

---

## 一、定位体制与选型决策（先决策，再部署）

部署方式由**定位体制**决定。系统支持两种定位体制，二者对信标部署的要求截然不同，**部署前必须先选定体制**：

| 维度 | 指纹定位（Fingerprint） | 三点定位（Trilateration） |
|------|------------------------|--------------------------|
| 定位原理 | 离线采集各点 RSSI 指纹库，在线查表匹配最近指纹点 | 在线接收 ≥3 信标 RSSI，按路径损耗模型反推距离、几何求交 |
| 信标覆盖要求 | **每点 ≥1 个信标可见即可**（越多指纹区分度越高） | **每点必须 ≥3 个信标可见**（几何求交的最低条件） |
| 功率一致性 | **不敏感**（指纹库是实测值，天然含功率信息） | **必须一致**（距离公式直接吃 TxPower，不一致则距离全偏） |
| 抗多径/穿墙 | **强**（直接存真实信号，多径反而构成指纹特征） | 弱（穿墙衰减使模型距离算错） |
| 离线建库 | 需要人工采集（工作量随面积线性增长） | 不需要（仅信标标定） |
| 在线算力 | 指纹向量匹配（轻量） | 解三边方程（更轻量） |
| 新区域扩展 | 难（需重新踩点） | 易（补几个信标坐标） |
| 适合场景 | 复杂室内、视障导航精度优先 | 需实时坐标、无采集条件、区域常变动 |

> **选型建议**：视障复杂室内优先**指纹定位**；若想"一套硬件两种体制通吃"，可部署**满足三点覆盖的信标密度**（即 ≥3 覆盖），则该密度天然满足指纹需求，后期可在指纹 / 三点 / 混合间自由切换。具体到本项目的三种候选方案（48 / 66 / 324 量级）详见 docs/08 §三。

## 二、信标选型标准

### 2.1 核心技术要求

| 要求项 | 规格 | 说明 |
|--------|------|------|
| 蓝牙版本 | BLE 5.0 | 微信小程序蓝牙适配器要求 BLE 4.0+，建议 BLE 5.x |
| 协议支持 | iBeacon（必备）+ Eddystone（可选） | 双帧兼容性更好 |
| 广播间隔 | 100~300ms 可配置 | 兼顾精度与续航 |
| 发射功率 | -28~+6 dBm 档位可调 | 见 §2.3 档位说明 |
| 电池续航 | ≥ 6 个月（本项目）；建议 1.5 年以上 | 减少维护成本 |
| 防护等级 | IP65 | 室内环境足够 |
| 电池 | CR2477 / CR2450，可更换 | 便于批量轮换 |

### 2.2 推荐芯片方案

| 档次 | 芯片方案 | 协议 | 参考单价 | 适用性 |
|------|---------|------|---------|--------|
| 最低配 | NRF51822 / DA14580 | iBeacon | ¥15~25 | 仅支持 BLE 4.2，不满足 BLE 5.0 要求，仅限预算极度受限时采用 |
| 推荐配 | nRF52810 / nRF52832 | iBeacon + Eddystone | ¥25~40 | 双帧兼容性更好，室内定位首选 |
| 中端配 | nRF52832 + 传感器 | iBeacon + Eddystone + TLM | ¥40~80 | 带遥测帧，可远程监控电池电量 |

**推荐选择**：nRF52832 方案（或同等 BLE 5.x 芯片），原因：
- 支持 iBeacon 和 Eddystone 双帧广播
- 参数可通过手机 APP 修改，灵活匹配数据库台账
- 是目前室内导航部署中最主流的芯片方案
- 稳定性和兼容性经过大量验证

> 具体到本项目，已在 docs/08 §二 落定三档成品型号（E5 领航型 ¥45 / E5 国产芯片版 ¥35 / 预算版 RF-B-SR1 ¥27），并附 Nordic vs 国产芯片的核心差异对比（docs/08 附录）。

### 2.3 发射功率档位说明（重要）

市售信标**实际可用的 TxPower 档位通常为 `-28 / -20 / -10 / -5 / -3 / 0 / 1 / 2 / 4 / 6 dBm`**，**没有 -8 / -12 dBm 档位**。因此：

- 分档部署（如"门口 -8、交叉口 -10、楼梯 -12"）在多数设备上**无法落地**；
- 统一取最近档 **-10 dBm** 对本项目影响可忽略（理由见 docs/08 §1.3）：
  - 覆盖无空洞：-10 dBm 室内可用距离约 15~20 m；
  - 指纹精度无损：指纹法靠原始 RSSI 指纹库，统一功率更一致、更易复现；
  - 跨层串扰可忽略：混凝土楼板衰减 15~30 dB，2 dB 差异被完全淹没。

### 2.4 采购渠道

- **国内首选**：1688 和京东上的深圳信标厂商（微能信息 95Power、铂礼、嘉之栋等）
- **国际可选**：MOKOSmart、Minew、Kontakt.io（价格更高，不建议课题项目采用）
- **采购策略**：先买 2~3 个样品做功能验证（UUID/Major/Minor/TxPower/Interval 可写 + 8m 外稳定扫描），确认稳定后再批量采购
- **批量折扣**：100 个以上订单通常可再降 10~20%

## 三、部署原则

### 3.1 决策节点优先

信标部署遵循"决策节点优先"原则，而非均匀覆盖。重点部署位置包括：

- 建筑入口和出口
- 楼梯与扶梯两端
- 电梯厅
- 长走廊的转角
- 交叉路口
- 重要房间门口
- 服务台
- 无障碍卫生间
- 商场主通道与停车场连接处
- 医院挂号、缴费、取药和检查区域

### 3.2 分层部署策略

| 区域 | 部署密度 | 定位精度 |
|------|---------|---------|
| 普通区域（走廊段） | 每 8~12 米布一个信标 | 约 2~5 米 |
| 关键节点（转角、门口） | 间距缩小到 3~5 米 | 提升到约 1~2 米 |
| 视障模式增强区 | 楼梯、扶梯、电梯、门口、道路交叉点加密 | 结合惯性传感器航向修正 |

### 3.3 视障模式增强

- 在楼梯、扶梯、电梯、门口和道路交叉点增加信标密度
- 结合手机陀螺仪、加速度计和电子罗盘进行航向修正
- 安全节点区域必须加密部署

### 3.4 两种体制下的部署密度差异

- **指纹定位**：走廊面按 1m 间距设**指纹采集点**（而非信标），信标只需保证每点 ≥1 可见；信标间距可放宽到 6m（本项目路线模式）。
- **三点定位**：信标间距必须满足任意可行走点 **≥3 可见**（本项目沿路线约每 6m + 拐角加密），密度显著高于指纹方案。

## 四、高风险节点部署方案

> 以下节点为视障导航最高风险区，无论采用哪种体制，均须优先加密覆盖。

### 4.1 楼梯与扶梯

楼梯与扶梯是视障导航的最高风险区域，部署密度必须最高：

```
    [预警信标]    ← 距入口 3~5 米，提前 2~3 秒播报安全提示
        |
    [入口信标]    ← 楼梯/扶梯入口处
        |
    [出口信标]    ← 楼梯/扶梯出口处
```

**部署要求**：
- 楼梯与扶梯两端入口各布一个信标
- 距入口 3~5 米处增设预警信标
- 确保系统在用户接近时能提前预警

### 4.2 电梯厅

电梯是视障用户的主要垂直通道，需要精确引导：

```
[厅入口信标] → [电梯口信标] → [厅内信标]
```

**部署要求**：
- 电梯厅入口处布一个信标
- 每个电梯门口布一个信标
- 厅内中央布一个信标

### 4.3 走廊交叉口

交叉口是路径决策点，需要多方向覆盖：

```
        [北向信标]
           |
[西线信标] ---交叉口--- [东线信标]
           |
        [南向信标]
```

**部署要求**：
- 交叉口四个方向各布一个信标
- 确保用户在任何方向接近都能被检测到

### 4.4 玻璃门与旋转门

```
[门侧信标] ---门--- [门侧信标]
```

**部署要求**：
- 玻璃门与旋转门两侧各布一个信标
- 触发高优先级安全预警

### 4.5 建筑出入口

```
[室外信标] ---入口--- [室内信标]
```

**部署要求**：
- 建筑出入口内外各布一个信标
- 室内信标作为导航起点
- 室外信标作为入口预警

## 五、信标参数配置

### 5.1 广播参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 广播间隔 | 300~400ms | 门口/交叉口 400ms；楼梯/电梯 300ms（兼顾精度与续航） |
| 发射功率 | **-10 dBm**（统一） | 设备无 -8/-12 档，取最近档 -10；覆盖半径约 15~20m，与 ≤6m 布点间距匹配 |
| UUID | 场馆维度统一 | 便于识别场馆 |
| Major | 楼层维度 | 便于定位楼层 |
| Minor | 节点维度 | 标识具体位置 |

> 密集节点区域若需缩小覆盖重叠，可在设备允许的档位内降功率（如 -20 dBm），但**同一次部署内所有信标必须同档**（三点定位硬约束）。

### 5.2 编码规范

每个信标配置全局唯一 UUID/Major/Minor：

```
UUID: B9407F30-F5F8-466E-AFF9-25556B57FE6D  (场馆维度)
Major: 1 (1楼) / 2 (2楼) / ...
Minor: 101 (入口) / 102 (转角) / 103 (交叉口) / ...
```

## 七、信标监控与维护

### 7.1 在线状态监控

系统定期（每 5 分钟）扫描场馆内信标广播，与台账比对：

- 发现离线信标立即告警
- 监控页面展示信标列表、在线状态、电池电量估算和最后心跳时间
- 告警通知通过邮件/短信发送给运维人员

### 7.2 电池电量监控

通过 BLE 遥测帧（TLM）获取电池电量：

- 电量 < 20%：预警通知
- 电量 < 10%：紧急通知
- 定期生成电池更换计划

### 7.3 信号异常检测

监控信号异常情况：

- 信号强度突然变化：可能遮挡或移位
- 广播频率异常：可能电池问题
- 位置漂移：可能被移动

### 7.4 维护周期

| 维护项 | 周期 | 说明 |
|--------|------|------|
| 在线状态检查 | 每 5 分钟 | 自动化监控 |
| 电池电量检查 | 每周 | 生成报告 |
| 信号强度抽检 | 每月 | 现场巡检 |
| 台账数据更新 | 每季度 | 核对物理状态 |

## 八、部署验收标准

### 8.1 通用验收

| 验收项 | 标准 | 检验方法 |
|--------|------|---------|
| 信标在线率 | ≥ 98% | 系统监控数据 |
| 安全节点覆盖率 | 100% | 逐点检查 |
| 台账与物理对应 | 100% | 现场核对 |
| 信号覆盖连续性 | 盲区 < 5% | 路测检查 |
| 安装高度统一 | 2.0~2.2m，同区域一致 | 现场抽查 |
| 无违规安装位 | 0 个（消防栓/疏散指示灯/弱电箱正面） | 现场核对 |
| 电池电压 | ≥ 2.8V（新电池） | 现场测量 |

### 8.2 体制相关验收

| 体制 | 附加验收项 | 标准 |
|------|-----------|------|
| 指纹定位 | 指纹点 RSSI 可重复性 | 同点两次采集偏差 > 5dBm 的点 < 20% |
| 三点定位 | ≥3 覆盖 | 目标区 ≥3 可见信标比例达标（本项目路线版 F1 92.5%/F2 86.1%，全楼版 F1 96.6%/F2 98.1%） |
| 三点定位 | 功率一致性 | 全部信标同档（统一 -10 dBm） |

## 九、部署规模估算方法

> 本项目（初中 1# 教学楼 1~2 层）的具体数量、坐标、采购清单与预算，以 `docs/08` 为准。本节给出通用估算思路，供其他建筑复制。

### 9.1 两种估算法

| 方法 | 公式 | 适用 |
|------|------|------|
| 节点法（指纹定位） | 走廊长度 ÷ 6m + 决策节点数 | 指纹定位（每点 ≥1 可见即可） |
| 覆盖法（三点定位） | 按可行走面积 1m 网格逐点仿真 ≥3 覆盖，缺口补点 | 三点定位（每点 ≥3 可见） |

### 9.2 参考量级（以 1,700m² 占地面积 × 2 层教学楼为例）

| 方案 | 信标量级 | 说明 |
|------|---------|------|
| 指纹定位（沿测试路线） | ~50 个 | 48 个（本项目路线基础） |
| 三点定位（沿测试路线） | ~60~75 个 | 60 基础 / 74 精化（本项目） |
| 三点定位（全楼层） | ~300+ 个 | 324 个（本项目全楼） |

> 三点定位信标数约为指纹定位的 **1.2~1.5 倍（路线级）** 或 **6~7 倍（全楼级）**，且必须全部同功率——这正是"指纹法更适合视障复杂室内、且更省钱"的量化依据。
