## ADR-01 门不合并（铁律）

- 状态：**已生效（用户铁律）**，2026-08-08 起
- 背景：旧实现曾将摆弧候选聚类后只保留一个，也曾在拓扑层按门中心距离合并；这些处理会丢弃不同门对象或混叠门与房间归属。
- 决策：**每个通过识别和有效性过滤的门对象独立成 TD 节点，禁止按距离、类型或几何相似度合并不同门对象**。同一 DK 标注在多种抽取方式中重复产生的候选，可在生成门对象前局部过滤。
- 影响：
  - `dedupe_doorways` 已从当前解析器删除；Git 历史仅用于追溯旧实现。
  - `_merge_nearby_doors` 曾存在于 `topology.py` 与 `pipeline.py`，本次已从当前源码删除；旧审查/解决日志仅为历史记录，不代表当前仍有可启用实现。
  - 校验按「每个门对象独立成 TD」设计。
- 恢复条件：任何门对象合并行为均须先取得用户明确确认，并同步修改解析、拓扑和一对一校验。

## ADR-02 手动骨架优先于自动中轴

- 状态：**已生效**，2026-08-08 起
- 背景：自动中轴骨架在复杂楼层会出现分支/缝隙问题，现场可人工标注 SVG 骨架。
- 决策：`skeleton_manual_parsed.json` 存在时跳过中轴提取（medial-axis），直接使用其 TI / TI-TI / 骨架线（含红色无填充矩形以闭合折线存入）；支持自动检测与 `--no-manual-skeleton` 强制自动。
- 影响：手动骨架 JSON 是拓扑生成的最高优先级输入；`import_manual_skeleton.py` / `apply_manual_skeleton.py` 构成标注闭环。
- 关联文档：`docs/项目迭代日志.md`（2026-08-08/08-09 条目）。
