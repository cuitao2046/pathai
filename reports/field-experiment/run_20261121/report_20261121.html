三、方案与配置说明

A/B/C 三臂共用同一份地图、信标台账和真值清单，区别只在定位机制与参数来源。 正式采集前通过「冻结配置」把三臂的参数与版本一次性写入实验配置，后续所有采集段都引用这份快照。

3.1 三臂定义

方案定位机制参数 / 数据来源前置依赖回退关系
A 默认参数 三点定位（对数距离路径损耗模型） 服务端出厂默认参数，不随现场标定变化 地图版本、信标台账 无
B 标定参数 三点定位，与 A 使用同一套算法 T3 现场标定并在校准控制台应用后，取当前生效的 LocationParamVersion T3 标定并应用 无
C 指纹库 指纹向量最近邻匹配（按点位聚合中位数） T4 采集并入库后的指纹库 active 版本 T4 采集 / 建库 未命中或超阈值时回退 B，并记录 fallbackReason

3.2 冻结配置内容

字段含义取值来源
configId / mapVersion / frozenAt配置编号、绑定地图版本、冻结时间（毫秒）冻结请求与最新地图
A.rssiAt1m / pathLossN / reliableM / degradedM / paramsVersionA 臂参数快照：1 m 处 RSSI、路径损耗指数、可靠 / 降级残差阈值、参数版本号服务端默认配置
B.*B 臂参数快照，字段与 A 相同已应用的现场标定参数版本
C.libraryVersion / fallback指纹库版本；回退目标固定为 B指纹库 active 指针
C.minOverlap / maxRmse / confidenceRmse / minConfidence / minMargin指纹命中阈值：最少重叠信标数、最大 RMSE、置信度归一化分母、最低置信度、与次优候选的最小差距代码常量 + 服务端配置
arrivalRadiusM / turnPromptDistanceM到达判定半径、转弯提前播报距离冻结时的运行参数

3.3 参数默认值与阈值

参数默认值作用
rssiAt1m-71.0 dBm1 m 处参考信号强度（measured power，不是信标广播 txPower）
pathLossN2.0路径损耗指数，自由空间为 2，遮挡环境通常更高
reliableM / degradedM1.5 m / 4.0 m残差可信 / 降级门槛，用于定位质量分级
minOverlap / maxRmse3 / 8.0 dBC 命中的最低重叠信标数与最大 RMSE
minConfidence / confidenceRmse0.55 / 20.0 dB置信度 =（1 − RMSE / 20）× 覆盖率，低于 0.55 判为低置信
minMargin3.0 dB最优与次优指纹点的 RMSE 差距，低于该值判为混淆

A 与 B 算法完全相同，差异只来自参数，因此两者之差即「标定增益」； C 未命中时回退 B，因此 C 与 B 之差即「指纹增益」，需结合「C 仅命中」视图解读。 当前导出的实验包尚无冻结配置（config 记录为 0），A/B/C 列的具体参数版本待冻结后生成。

对比规则（T0.4）
  • 只做相对排序，不设绝对 PASS/FAIL；差异不显著时标为同档。
  • 单指标先排序，再看 Pareto 支配关系；条件性差异按场景单独给出。

  • 仅在同一地图版本、同一真值清单、同一设备与同一冻结配置下横向比较。

六、补齐路径

  1. 完成 T3 标定并冻结配置：当前 CAL 只覆盖 2 个点位，需按正式计划完成 12 点 × 3 窗口并通过校准控制台应用参数；随后冻结配置。冻结后的 A（默认参数）/ B（标定参数）/ C（指纹库）才具备可比性。
  2. 按正式计划重采 T6：18 个点位 × 4 朝向，每段 ≥ 30 s。当前 5 段中 4 段为试采、1 段异常，且 10 s 窗口低于正式要求。
  3. 补齐 T8 导航对比：至少 8 个点位，每点位分别以 A / B / C 三轮导航，采集后才能计算有效定位率、跳变、更新间隔、RTT、指令→播报与到达延迟。
  4. 更新客户端后再采 T8：确保 estimate 事件写入 visibleBeaconCount 与 requestMs，否则 RTT 指标仍为空。
  5. 重新导出并一键重算：按文末命令执行导出 → 批量重放 → 分析；报告会自动填充准确性与时效表格。
