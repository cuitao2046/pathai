## ⚠️ 工具环境故障（本次新发现，重要）
- **Bash 工具 PATH 损坏**：`cd`/`dirname`/`head` 全部 "command not found"，报错源自 `shim/shell-runtime-bash-env.sh: line 3: dirname: command not found` + `cd: null directory`。→ Bash 基本不可用，命令即使 exit 0 也无实际执行。
- **PowerShell 工具可用，但 stdout 不回显**：`& python.exe -c "..."` 返回 "Command completed with exit code 0" 却看不到任何输出。
- **可行绕法（已验证）**：写 Python 脚本 → 脚本内 `open(...,'w').write(...)` 把结果写到文件 → 用 Read 读取该文件。本次巡检 geojson 全靠此法完成。
- 结论：本环境下**不要再依赖 Bash 做数据处理**；需要输出就用「脚本写文件 + Read」模式。Glob/Grep/Read/Write 工具本身正常。
- 另：`find` 命令同样受 PATH 影响不可用，列目录改用 Glob。
