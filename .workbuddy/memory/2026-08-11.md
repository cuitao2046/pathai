  2. ⚠️ **fetch 声称成功 ≠ refs 落盘**：`git fetch` 输出 `master -> origin/master` 但 `for-each-ref` 仍显示旧 SHA（沙箱 refs 写入失败）→ 必须用 `git for-each-ref refs/remotes/` 验证；失败时手动 `printf <sha> > .git/refs/remotes/origin/<branch>`。
  3. **改动前先 `git branch --show-current`** 确认不在 master 上直接开发（铁律 0）。

  - `git rm -f` / `git checkout -b` 在异常 index/损坏仓库上会误删工作区文件、创建空分支 → 恢复用 `git archive <commit>` 从 pack 提取，比手修 refs 可靠。
