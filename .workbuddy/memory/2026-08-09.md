# 经验（需求⑤）
- **"穿墙"判定口径**：`route_rules._segment_crosses_wall` 把端点恰在墙线上也算穿墙(t≈1 过内部测试)——对"门在墙上"的合法边是误报。房间↔门边的正确指标是「线段是否严格穿过墙体」，不能直接复用该函数；走廊类边排除门/设施端点后可用。
- **非凸房间硬下限**：多房间共享门 + 非凸排布时，单门节点单条直边必穿墙（本项目 42 条为硬下限）。正确拓扑是**门拆子节点**（hub+每房间子节点），而非调房间质心（实验证明质心位置 50/50/51 无差别）。
- **slatted 房间**：房间多边形内部含整跨隔墙（解析数据质量）时任何单直边都穿墙，只能接受为残余并记录，不可作为放置 bug 继续调。
- **门 `rooms` 字段不可信**：几何门 id 与拓扑 TD 存在系统性漂移（26 处 doorType/rooms 不一致），实际连边以 edges 为准，勿按 geometry.doors 匹配归位。
