- **问题**：用户反馈渲染图中"走道"等文字标注的几何矩形与电梯井等封闭空间重叠。

  - 鞋带公式算面积 + 包围盒算长宽比；满足「面积 < 6m² 且 长宽比 ≥ 1.5」即判定为文字框，跳过绘制。

## 走道巨型 blob 切分 + 活动空间零门豁免（本轮收尾）

- **背景**：前一轮已根治「走道侵入房间」（根因是 `comp_at` 欧氏方框投票跨墙把未封闭走道标签误挂到相邻房间触发几何分割切角；美术工作室恢复 99.4m²）。但真实走廊提取（墙膨胀封口→室外反膨胀→内部自由域减已识别房间）产出一个**覆盖整层的巨型走廊多边形**（F1=3157m²/1857顶点），因为主走道串联各分区连通成一片。
- **本轮修复（`src/parse_cad_pdf.py` `build_rooms` 交通域提取段）**：
  1. 把「按连通域整体成面」改为「按开放空间标注做最近邻(Voronoi)切分」，每段走道各自成面、质心落真实走道。
  2. 原 `cv2.distanceTransformWithLabels` 实现**根本性错误**：种子点被画成源图上的黑洞，整片前景成为单一连通域 → `seg_key` 全 0 → 不切分（行为回退到不切分，且 `_OPEN_ALL` 未定义、`owner[ccc==ci]` 中 `ci` 未定义两处 bug）。

  4. 顺手修正两处命名 bug：`_OPEN_ALL`→`_OPEN_RT`；`owner[ccc==ci]`→`owner[combo==key]`；scipy 调用必须有 `return_distances=True` 才能按 `(dist,(iy,ix))` 解包（否则 `too many values to unpack`）。
