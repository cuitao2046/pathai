## 空间分解模块（spatial_decompose.py，2026-08-07 晚）
- 新建 src/spatial_decompose.py：基于中轴骨架的 walkable 空间分解成独立几何块。
- 核心算法：对每条骨架线在两端做垂直截线，截线与 walkable polygon 的交点构成四边形 → 裁剪 → 独立块。支持 MultiPolygon 多组件。
- 集成到 parse_cad_pdf.py floor_block：在 T1 walkable 之后调用 build_skeleton_for_walkables → decompose → classify_block → 写入 geojson["spatial_blocks"]。
- v1 实测：F1 195 块 / F2 92 块 / 合计 287 块（缺 525 条中轴段因长度<0.3m 跳过，多为骨架边缘碎枝）。
- 分类器 v1 较粗糙：stair_lobby 偏多（110 个 vs 原来 6 个），根因是分解后贴楼梯的每个小块都被独立判为前室；后续需基于块连接度/袋形检测优化。
- 骨架管线需 scikit-image + networkx，已安装到 managed Python 3.13.12。
