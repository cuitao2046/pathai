## 空间分解 v2：polygonize 分区（2026-08-07 下午）
- 用户反馈空间块存在 overlap、公共区域覆盖不完整、形状不符合"近似矩形+三角形"预期。
- 根因分析：v1 对每条骨架段独立做垂直截线，相邻段在 shared junction 处产生不同截线 → block 重叠且漏空。
- v2 方案（重写 spatial_decompose.py，从 ~365行 扩容至 ~470行）：
  1. `_build_endpoint_clusters`：按 canonical grid 聚类骨架端点，区分 junction(≥2段汇聚) 和 terminal(仅1段)
  2. `generate_cut_lines`：junction 处用**角平分线**作为共享分界线（按角度排序相邻方向算 bisector）；terminal 处保留垂直截线
  3. `_polygonize_partition`：`unary_union(boundary + cuts) → polygonize` 生成无重叠、全覆盖的子多边形
  4. `_assign_polygons_to_segments` + `_build_blocks_for_lines`：子多边形→最近骨架段归类→合并→块元数据
  5. 全局去重叠（主函数末尾逐块 Difference 清扫残留 sliver）
  6. 每 polygon 组件独立处理（`_lines_touching_poly` 过滤），避免跨组件分界污染
- 验证（合成测试 + 真数据全流程）：
  - 合成 L 形走廊：2 块、无重叠、全覆盖、rect 形状 ✅
  - 真数据：F1=180 块(2462.2m² → 合并=2462.2m², overlap=**0.00%**)；F2=89 块(1268.5m² → 合并=1268.5m², overlap=**0.00%**)
  - 形状：82% rect + 18% trapezoid
  - 全流程 0 WARN/0 ERROR/0 异常
