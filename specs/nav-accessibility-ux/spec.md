# Spec：导航无障碍交互优化（全屏按住说话 + 导航方向箭头）

> **版本：** 0.3.0（已确认，实施中；0.3.0 重做箭头形态）
> **日期：** 2026-11-05
> **状态：** 已拍板（Approved）——Q1–Q12 与追加的模式设置均已定稿，按 `tasks.md` 实施
> **关联：** `specs/phase-1-indoor-navigation/spec.md`（REQ-A11Y、REQ-NAV、REQ-VOICE）、
> `specs/field-collection-integration/spec.md`（首页工具条与采集入口）、
> `client/pages/map/map.ts`、`client/styles/map-tools.wxss`

---

## 1. 背景与目标

当前首页（`pages/map/map`）的语音入口是底部居中的「按住说话」按钮 `.ptt-zone`
（`client/pages/map/map.wxml#L149-L159`，`map.ts#L849-L865` 调用 `PushToTalk.begin/end/cancel`）。
视障用户要在屏幕上"摸到"这一小块才能开口；导航态又缺少**不依赖精细视觉**的方向指示。

本 spec 定义两项增强：

1. **全屏按住说话**：首页启动完成后，除可见控件矩形外，屏幕上任意位置单指按住即可开始语音，
   与点按「按住说话」完全等价。
2. **导航方向大箭头**：导航进行中全屏展示高对比度大箭头，指示"当前位置应当行进的方向"，
   并配合"对齐 / 偏离"的非视觉（震动 + 语音）反馈，让半盲用户能判断手机朝向是否与路线一致。

**目标用户：** 全盲（依赖语音/震动）、半盲/低视力（依赖高对比图形）、单手操作者。

---

## 2. 范围与不包含

**包含：** 首页（待命态 + 导航态）的触摸手势判定与排除区域、语音反馈、方向箭头渲染与传感器管线、
验收指标、设置项与降级策略。

**不包含：** 语音识别引擎/意图解析改造（沿用 `PushToTalk` + `intents.parse`）；
路线规划与定位精度改造；地图旋转（当前 `FloorMapViewport` 仅支持平移/缩放，**不支持旋转**，
即屏幕上方恒为地图北向）；无障碍读屏框架替换；采集页（`pages/collect/*`）。

---

## 3. Spec 归属决策（新建独立目录）

**结论：新建 `specs/nav-accessibility-ux/spec.md`（本文件），不并入 `phase-1-indoor-navigation`。**

理由：

1. **关注点独立**：本需求是"交互/感知层"的无障碍增强（手势仲裁 + 传感器可视化），
   与主流程（定位、意图、会话、地图版本）解耦，可作为独立特性评审、独立开关、独立回滚。
2. **跨状态且跨轮次**：同时影响待命态与导航态，后续很可能继续追加（如语音播报策略、
   高对比主题），独立目录便于演进版本而不牵动 P0 主 spec。
3. **避免污染 P0 文本**：`phase-1` spec 已至 0.3.7、章节长且被多次评审；插入手势优先级矩阵
   与传感器参数会稀释主流程可读性。
4. **仓库已有先例**：`specs/field-collection-integration/`、`specs/local-service-discovery/`、
   `specs/voice-agent-*` 均为独立特性目录。

**追踪关系：** 本 spec 确认后，在 `phase-1` 的 **REQ-A11Y** 追加一行引用
（"全屏按住说话与方向箭头见 `specs/nav-accessibility-ux/spec.md`"）并升版本至 0.3.8；
本轮同步更新 `phase-1` 的 REQ-A11Y 交叉引用。

## 3.1 无障碍模式设置（REQ-A11Y-MODE）

| 项 | 取值 |
|---|---|
| 设置页位置 | `pages/settings/settings` 的「无障碍模式」分组，第 1 行 |
| 开关语义 | **开 = 视障模式（默认）**；**关 = 普通模式** |
| 存储 | kv `cfg:a11yMode`，值 `'a11y' | 'normal'`，缺省按 `'a11y'` |
| 生效时机 | **即时生效**（含进行中的导航）：返回首页 `onShow` 回读并重绘 |

**视障模式（默认）：**
- 导航中显示高对比度大方向箭头（§5）；
- 全屏单指按住说话生效（§4，仍受「全屏按住说话」子开关控制）。

**普通模式：**
- **不**渲染大箭头，导航保持既有 HUD + 地图 + 逐向语音展示；
- **不**启用全屏按住说话：单指按下**立即拖拽地图**（无 500ms 判定、无 10px 死区），
  底部「按住说话」按钮照常可用；
- 导航核心逻辑（路线、定位、HUD、语音、震动）与视障模式完全一致，不缺失功能。

**理由（即时生效）：** 模式是"感知能力"的声明而非一次性配置，用户（或陪护者）在导航过程中
发现看不清箭头时才切换，若需重启导航会打断行走；即时重绘成本低（仅隐藏/显示覆盖层）。

**与 Q11「夜间/强对比」的关系（自主决策）：合并为一个维度。**
原 Q11 的「夜间/强对比」开关并入本模式开关：视障模式即高对比表达（箭头浅底深蓝、深底亮黄），
普通模式沿用现有浅色 UI；箭头配色仍**跟随系统深浅色**（`theme === 'dark'` 时用深底亮黄）。
不新增独立配色开关，避免设置页出现"视障模式关 + 强对比开"这类自相矛盾的组合。

**子开关（仅视障模式生效，默认均为开）：**
- 「全屏按住说话」`cfg:fullScreenPtt`，关闭后只保留底部语音键；
- 「导航方向大箭头」`cfg:navArrow`，关闭后导航态不显示箭头、不做偏离播报（HUD 与逐向语音不变）。

**切换反馈：** 无震动、无语音播报，仅 `wx.showToast` 文案（避免在安静环境突然发声引起尴尬）。

## 4. 全屏按住说话（REQ-A11Y-GESTURE）

### 4.1 触发条件（已拍板参数）

| 参数 | 取值 | 说明 |
|---|---|---|
| 模式 | **视障模式**（`cfg:a11yMode !== 'normal'`）且「全屏按住说话」开关为开 | 普通模式完全不启用本功能 |
| 手指数 | 恰好 1 指 | 2 指及以上一律判为地图缩放，不进入语音 |
| 长按时长 | **500 ms** | 从 `touchstart` 起算；短于阈值视为普通触摸 |
| 位移阈值 | **≤ 10 px**（相对触点起点） | 超过即取消语音候选，转为地图拖拽 |
| 持续时间上限 | **15 s** | 到时自动结束并提交，防止误触后长时间占用麦克风 |
| 前置条件 | 首页已启动完成 | `mapReady === true` 且 `loading === false`、`loadError === ''`（沿用 `onPttStart` 门） |

**判定流程（状态机）：**

```
touchstart(1 指, 非排除区) → pending
  ├─ 移动 > 10px        → 取消 pending，进入地图拖拽（pan）
  ├─ 500ms 到达且仍静止 → 进入语音态（等价 onPttStart）
  └─ 500ms 前抬手        → 无动作（视为轻触/点选，交由现有逻辑）
语音态中：移动 > 10px 不取消（沿用按住说话"按住即可说话"的容错）；
         抬手 → 等价 onPttEnd；touchcancel → 等价 onPttCancel
```

### 4.2 排除区域（按下即不参与语音判定）

1. **「按住说话」按钮** `.ptt-zone` 及其命中矩形（该区域由自身 `bindtouchstart` 处理，天然不进 canvas 流）。
2. **左侧工具条** `.top-left` 的 4 颗：设置 / 楼层触发 / 全图 / 采集触发（含楼层与采集**展开后的全部候选**）。
3. **导航 HUD** `.nav-hud` 内所有可点控件（结束导航 / 关闭）及其实际命中矩形。
4. **居中卡片** `.center-card` 整体（含关闭、候选、开始导航按钮）——浮层出现时视为模态。
5. **加载/错误覆盖层** `.overlay`（`loading` 或 `loadError !== ''` 时整屏排除）。
6. 其他**任何可见的 `aria-role="button"`/`bindtap` 控件**：以 `wx.createSelectorQuery()
   .selectAll('[aria-role="button"], .zoom-hit, .ptt-zone, .nav-hud control, .center-card')
   .boundingClientRect()` 采样出的矩形为准（含 padding 后的热区，而非仅可视面）。
7. 系统区域：顶部胶囊/导航栏（不在页面坐标系内，天然不触发）。

**刷新时机：** 页面 `onReady`、`floorMenuOpen`/`collectMenuOpen` 变化、`navActive` 变化、
`center-card` 出现/消失、屏幕旋转/窗口尺寸变化（`onResize`）时重新采样；
采样结果缓存为"排除矩形集合"，判定用页面坐标（`toCanvasPoint` 同一坐标系）。
**容错：** 采样失败或矩形为空时退化为"仅排除 `.ptt-zone` + 工具条静态矩形"，
并在日志记 `warn`（不得因为采样失败而整屏禁用语音）。

### 4.3 与现有手势的优先级

现有实现（`map.ts#L664-L727`）：canvas 上 `catchtouchstart/move/end`，**单指按下立即进入 pan**，
双指进入 zoom；控件是 canvas 的兄弟节点，不进入该事件流。

**冲突结论：** 全部手势必须在 canvas 自身的触摸流内仲裁（**不得新增全屏覆盖层**——
覆盖层会吞掉地图手势与控件点按，也违背现有"控件为兄弟节点"的规避设计）。

**仲裁优先级（高 → 低）：**

| 优先级 | 手势 | 处理 |
|---|---|---|
| 1 | 双指（≥2 指） | 立即 zoom，取消任何语音候选 |
| 2 | 排除区域内的单指 | 不进入本功能（交由该控件 / 地图原逻辑） |
| 3 | 单指静止 ≥500ms | 语音（等价 PTT） |
| 4 | 单指移动 >10px（含 500ms 前） | 地图拖拽 pan |
| 5 | 单指静止 <500ms 即抬起 | 现有轻触逻辑（点选/无动作），不改语义 |

**相对现有行为的变化（仅视障模式）：** 单指拖拽增加 **10px 启动死区**（需先移动 10px 才开始 pan），
换取语音可触发性；zoom 不受影响。**普通模式不改变任何地图手势**：单指按下立即拖拽
（无 pending、无死区），不进入语音。死区 10px 低于现有拖拽可感知阈值，实测需确认不影响
"精细对位"体验（导航态地图自动跟随，用户手动拖拽多为大范围浏览）。

### 4.4 触发后的行为与反馈

- **等价性：** 与点按 `.ptt-zone` 完全一致——`appContext.voicePrompts.stop()` 抢占提示音 →
  `onDismissIntent()` 收起旧卡 → `PushToTalk.begin()`；抬手 → `end()`；`touchcancel` → `cancel()`。
- **视觉：** `.ptt-zone` 进入 `recording` 态（现有背景色 + `ptt-hint` 文案"松开结束"），
  即使手指不在按钮上，也同步高亮，给陪护者/半盲用户一个可瞄的参照。
- **震动：** 进入 `recording` 时短振一次（复用现有 `onStateChange` 逻辑，`map.ts#L834-L836`）。
- **语音提示（Q4 拍板：仅震动）：** 进入/结束语音态**不播放任何提示语音或提示音**，
  只用震动 + `.ptt-zone` 状态文案承担确认；理由：避免"请说话"提示被 ASR 采入形成回环、
  避免公共场合打扰，也与现有底部按住说话的反馈完全一致（不引入两套听觉语义）。
- **不重复采集：** 语音态期间若手指移出排除区、移到地图其他位置，不重新判定、不重开录音。

### 4.5 无障碍语义

- 手势本身不依赖视觉；进入/结束语音态必须可被**非视觉感知**（震动 + 语音）。
- 屏幕阅读器（TalkBack/VoiceOver）场景：长按是读屏常用手势（长按选中），存在冲突风险。
  小程序侧无法可靠检测读屏状态 → 提供**设置页开关「全屏按住说话」**（默认开），
  读屏用户可关闭并继续用 `.ptt-zone`；开关写入 kv 即时生效（与「现场采集工具」同一机制）。
- 不截获双击：本功能只响应"静止长按"，不消费双击/连击（符合 `phase-1` REQ-A11Y
  "双击不得作为屏幕全局手势截获"）。

### 4.6 失败与边界

| 场景 | 处理 |
|---|---|
| 地图未就绪 / 加载中 | 不触发（沿用 `mapReady` 门） |
| 蓝牙/麦克风权限拒绝 | 沿用 `PushToTalk.onError`：语音播报错误 + 可访问文本，不静默 |
| 触摸点落在两个排除区之间的 1px 缝隙 | 以"最近排除区向外扩 2px"判定，避免边缘误触 |
| 多指退化为单指 | 不进入语音（要求从 `touchstart` 起就是单指） |
| 页面切后台 | `touchcancel` → `cancel()`，不残留录音 |

## 5. 导航方向大箭头（REQ-A11Y-ARROW）

### 5.1 图形与尺寸

- **形态（0.3.0 重做）：** 「**宽箭头 + 窄箭身 + 单侧尖顶**」的楔形箭头，**不再使用等边三角形**。
  - 尖顶位于中轴正上方，顶角约 **49°**；等边三角形三个角都是 60°、没有"头/尾"差异，
    半盲用户无法判断哪一端是行进方向（0.2.0 形态的问题）。
  - 箭头（头部）宽 64%、高 50%，是全形最宽处；箭身仅 22% 宽、延伸到 96% 高度，
    形成明确的"头宽 / 尾窄"对比，旋转到任意角度都能一眼分出前后。
  - 图形关于中轴（x = 50%）严格对称；包围盒 300×420rpx，位于既有 520rpx 圆盘内
    （**覆盖层外框尺寸与位置不变**：`left:50%`、`top:55%`、中心屏高 55%）。
  - 几何单一真源：`client/core/a11y/nav-arrow-shape.ts` 导出顶点、尖顶角与描边缩放，
    WXML 的 `clip-path` 由它下发；单测锁定"尖顶角 <55°、头宽 ≥2.5× 身宽、关于中轴对称、
    箭身到尾"等形态约束，防止后续调形退化。
- **对准参考线（新增）：** 圆盘顶部固定 1 条 **10×52rpx 刻度**，**不随箭头旋转**，
  代表"手机正前方"。用户只需比较"箭头尖端是否与环顶刻度对齐"即可判断是否对准。
  - 理由：箭头角是**相对手机朝向**的（§5.3），如果整块图形一起转，屏幕上方缺少绝对参照，
    半盲用户难以把"箭头朝上"和"手机正对路线"对应起来；固定刻度补上这个参照。
  - 安全/性能：刻度只有 1 个 `view`、位于非旋转层，不改变旋转帧率与命中区域；
    全部元素仍在 `pointer-events:none` 覆盖层内。
- **实现方式：** WXML `view` + `clip-path` 多边形（外层描边层 100%、内层填充层 90% 缩放），
  旋转仅作用于内部转子 `nav-arrow-rotor`（`transform: rotate()`，`will-change: transform`）。
  - 理由：不用 canvas——避免与地图 `requestDraw` 重绘耦合；不用图片/SVG 资源——无网络与
    解码开销、多主题/警示态只改背景色；不用 CSS 边框三角——无法表达"宽头 + 窄身"的非等边造型。
  - 性能：两个静态多边形节点 + 单个 `transform` 旋转，旋转期间无布局/尺寸变化，
    沿用既有 ≤2°/50ms 的重绘节流，满足 ≥20fps 且无重绘抖动。
- **尺寸：** 覆盖层圆盘 520rpx（375px 屏约 **260px** ≈ 70vw），中心屏高 **55%**，
  不与顶部 HUD（`top:24rpx`）和底部 `.ptt-zone`（`bottom:64rpx`）重叠（结论不变）。
- **层：** WXML `view` 覆盖层（`pointer-events: none`，`z-index: 20`，位于地图之上、HUD(30) 之下），
  不用 canvas 绘制——避免与地图重绘耦合、便于无障碍树读取与样式切换。
- **不遮挡：** 覆盖层整体 `pointer-events: none`，且与工具条（左上、宽 ≤190px）横向不重叠
  （箭头左缘 ≈ 屏宽 15% = 62px 起，已按 Q1 结论复核）。

### 5.2 配色与对比度目标

| 场景 | 前景 | 背景衬底 | 目标对比度 |
|---|---|---|---|
| 浅色地图（默认） | `#0B3D91`（深蓝） | `#FFFFFF` 不透明衬底（圆角矩形，α=0.92） | **≥ 7:1**（实测 **10.0:1**） |
| 系统深色（`theme === 'dark'`） | `#FFD400`（亮黄） | `#000000` 衬底（α=0.92） | **≥ 12:1**（实测 **14.7:1**） |
| 偏离 >30° | `#B00000`（深红）+ 白色描边 | 同上 | **≥ 7:1**（实测 **7.4:1**；深色主题红/白相邻 7.4:1、白描边/黑衬底 21:1） |

> **警示红取值（0.3.0）：** Q6 的"红色 + 白描边"保留，但把 `#D50000`（对白 ≈5.0:1）
> 改为 `#B00000`（对白 ≈7.4:1），才能满足本节 ≥7:1 的内控门槛；色相仍为红，
> 并以红环、偏离语音与 ≥5 s 节流共同承担警示语义。

> **Q11 处理：** 「夜间/强对比」不单独设开关，配色跟随系统深浅色并只在视障模式生效
> （见 §3.1 自主决策）。

要求：图形/背景对比度按 **WCAG 2.1 非文本对比度 1.4.11** 门槛 **≥ 3:1**，
本项目内控门槛提高为 **≥ 7:1**（AAA 级大图形），并在 `tasks.md` 中提供取色校验脚本。

### 5.3 指向依据：推荐**相对手机朝向**

| 方案 | 定义 | 优点 | 缺点 |
|---|---|---|---|
| A. 屏幕内绝对方位 | 箭头指向"路线在屏幕上的方向"（屏幕上方=北） | 与地图一致，实现简单 | **无法回答"我的手机朝向是否对准路线"**——箭头固定，用户转动手机看不到变化 |
| **B. 相对手机朝向（推荐）** | 箭头角度 = 路线方位角 − 手机朝向角（相对屏幕上方）；**箭头朝上 ⇔ 手机正对路线** | 用户只需转动身体直到箭头朝上；可与"向左/右转 X 度"语音直接对应；适合半盲与全盲 | 依赖罗盘精度；需要处理抖动与 360° 回绕 |

**推荐 B**，理由：需求原文正是"判断手机指向与路线方向是否一致"，A 方案在信息上无法完成该判断；
B 把判定简化为"箭头是否朝上"，是最省认知的对齐编码，也天然支持语音提示。

**同时保留 A 的信息**：箭头下方小字/（可选）语音"路线在你的 10 点钟方向"用于绝对方位参考（非必需）。

### 5.4 朝向数据来源与降级

| 优先级 | API | 用途 | 说明 |
|---|---|---|---|
| 1 | `wx.startCompass({ interval: 'normal' })` + `wx.onCompassChange` | 磁方位角 `direction`（0–360°，屏幕上方） | 提供绝对方位，精度字段 `accuracy` 可用于降级 |
| 2 | `wx.startDeviceMotionListening({ interval: 'ui' })` + `wx.onDeviceMotionChange` | `alpha` 相对角变化量 | 无罗盘时以"首次按住语音/首次显示箭头"为基准，仅提供相对变化（箭头可判断转动量，但初始基准未对齐） |
| 3 | 降级 | 隐藏箭头 + 语音"当前设备无法提供方向" + 继续文字/语音指令导航 | 不静默显示错误方向 |

- **横竖屏：** 锁定竖屏（`pageOrientation: portrait`，Q8 拍板；`app.json` window 级配置）；若系统允许横屏，
  用 `wx.onDeviceOrientationChange` 读取并补偿 90°。
- **生命周期：** `navActive` 为 true 时启动，结束/关闭导航、`onHide`、页面卸载时
  `wx.stopCompass` / `wx.stopDeviceMotionListening`（省电，且避免后台耗电被系统限流）。
- **失败处理：** 罗盘 `accuracy` 无值或连续 3 次回调异常 → 降级到方案 2；均失败 → 方案 3，
  并记录一次 `log.warn`。

### 5.5 刷新频率与平滑

- **数据频率：** 罗盘 `normal`（约 5 Hz）；必要时用 `ui`（更高频率）——以耗电实测决定（Q5）。
- **平滑：** 角度一阶低通（EMA，`α = 0.15`，按 5 Hz 计）；跨 0°/360° 用最短弧差处理；
  静止判定：连续 1 s 角度变化 < 3° 则冻结显示（避免细小抖动）。
- **视觉刷新：** 目标 **≥20 fps**（受 `requestDraw` 节流保护，不与地图重绘叠加重复帧）；
  角度变化 < 2° 时不重绘。旋转只作用于箭头转子，衬底、参考环与环顶刻度保持静止，
  不触发布局变化（0.3.0）。
- **抖动指标：** 静止 3 s 内显示角度波动 ≤ **±2°**。

### 5.6 偏离容差与提示

| 偏离角 \|Δ\| | 视觉 | 非视觉 |
|---|---|---|
| ≤ 15° | 箭头"对齐态"（实心/绿色描边环闭合） | 首次进入对齐：短振 1 次 + 语音"方向已对准，请直行"（每次会话只播 1 次，避免反复） |
| 15°–30° | 箭头正常态（黄/蓝） | 不主动播报（仅继续现有导航指令） |
| > 30° 持续 ≥ 2 s | 箭头警示态（红 + 描边加粗） | 语音"方向偏离约 X 度，请向{左/右}转"，**节流 ≥ 5 s**，且不得压过安全提示（走 `SpeechQueue` 的 `normal` 优先级，安全提示可打断） |

- 偏离角取"路线当前折线段方向"与"手机朝向"的最短夹角；X = 取整到 15° 档（15/30/45…）。
- 位置质量不可信（`unreliable`/`lost`）时：箭头转灰 + 语音降级提示，且不播报方向偏离
  （符合 `phase-1` REQ-NAV"低质量定位以安全提示替代方向指令"）。

### 5.7 显示条件

- **模式：** 必须为视障模式（`cfg:a11yMode === 'a11y'`）且「导航方向大箭头」开关为开。
- **导航状态：** 仅导航进行中（`navActive === true && !ended`）显示；待命态、结束态、
  错误态、定位恢复态（`recovering`）一律不显示（恢复态不显示可能错误的方向）。
- 无有效朝向数据（传感器不可用）→ 不显示并语音降级提示（§5.4 方案 3）。
- 切换模式/开关为**即时生效**：关闭后立即隐藏箭头并停止传感器；开启后若导航进行中立即重绘。
- 居中卡片/HUD 弹层出现时箭头仍可显示（HUD 在其上方，`z-index` 已分层），但若遮挡超过 30% 面积则缩小 20%。
- 导航结束后 1 s 内淡出（可选），避免"箭头残留"造成误导。

### 5.8 视障/半盲可用性要点

- 半盲：大箭头 + 环参考 + 高对比，可在 1 m 距离辨认（验收见 §6）。
- 全盲：箭头不可见 → 依赖"对齐/偏离"语音与震动；进入对齐的短振是"停下转动"的确认信号。
- 不新增仅视觉可用的关键信息：所有关键状态（对齐、偏离、朝向不可用）均有语音或震动对应。
- 箭头不替代既有逐向语音指令；二者同源（同一条当前折线段），不产生矛盾播报。

## 6. 验收标准（可测量）

| # | 指标 | 门槛 | 测量方法 |
|---|---|---|---|
| A1 | 拖拽误触发语音率 | ≤ 1%（100 次 ≥20px 拖拽，0–1 次误触发） | 实机夹具：模拟 touch 序列 + 计数 |
| A2 | 排除区误触发率 | 0%（各控件矩形内各 20 次按下，含展开候选） | 逐控件脚本化触摸 |
| A3 | 触屏到震动反馈时延 | P95 ≤ 700 ms（阈值 500 ms + 处理/播报 ≤200 ms） | `touchstart` 打点 vs 震动调用打点 |
| A4 | 长按未及阈值不触发 | 100%（300 ms 抬手 20 次，0 次触发） | 同上 |
| A5 | 进入/结束语音态**无任何语音提示**（Q4 仅震动） | 0 次 TTS/提示音调用；仅 1 次 `vibrateShort` 与状态文案 | 断言 `SpeechQueue` 未新增条目 + 震动调用计数 |
| A6 | 普通模式不改变地图手势 | 单指按下即进入 pan（无 500ms 等待、无 10px 死区），0 次语音触发 | 单测 + 真机手势计时 |
| B1 | 箭头刷新率 | ≥ 20 fps（静态显示时按需重绘；旋转时不低于 15 fps） | 帧计数 + trace |
| B2 | 静止抖动 | 显示角度波动 ≤ ±2°（静止 3 s） | 记录角度序列求极差 |
| B3 | 朝向误差 | 与参考罗盘（专业 App）同姿态误差 ≤ ±5° | 8 方位 × 3 次取均值 |
| B4 | 箭头对比度 | ≥ 7:1（两套配色均达标，深色方案 ≥ 12:1） | 颜色计算脚本（WCAG 公式） |
| B5 | 对齐判定 | 偏离 ≤15° 时箭头在屏幕上方 ±5° 内；>30° 持续 2 s 才播报 | 角度注入测试 + 播报日志 |
| B6 | 播报节流 | 偏离播报间隔 ≥ 5 s，安全提示可打断普通播报 | `SpeechQueue` 日志断言 |
| B7 | 传感器生命周期 | 导航结束/切后台后罗盘与运动监听已停止（0 个活跃监听） | 监听计数断言 |

**必要单测（实现阶段）：** 手势仲裁状态机（pending/pan/voice 转移、阈值边界 499/500/501ms、
9/10/11px）、排除矩形命中（含 2px 外扩）、角度差最短弧、EMA 平滑与静止冻结、
偏离分档（14° / 15° / 31°）。

## 8. 风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| 长按与读屏软件手势冲突 | 视障用户无法使用 VoiceOver/TalkBack 选取控件 | Q9 设置开关；不做全局双击拦截；在设置页给出说明 |
| 10px 死区影响精细拖拽 | 地图对位体验下降 | 仅对"单指静止"生效；双指缩放不受限；可配置 |
| 罗盘精度差（金属/电磁干扰） | 箭头指向错误，误导半盲用户 | `accuracy` 阈值 + 降级方案 + 偏离提示使用相对变化；位置不可信时不播报方向 |
| 传感器常开耗电 | 导航时长受限 | 仅导航态启动；`onHide` 即停止；Q5 频率可调 |
| 覆盖层遮挡地图点击 | 误操作 | `pointer-events: none` + 排除区采样 |
| 与既有 PTT 状态机并发 | 双重录音 | 单一 `PushToTalk` 实例；语音态互斥，`begin()` 重复调用需幂等 |

**回滚：** 功能以模式开关 + 两个子开关（「全屏按住说话」「导航方向箭头」）控制，默认开；
关闭（普通模式）后回到 v0.3.7 的地图手势与导航展示行为，无数据迁移、无后端影响。
